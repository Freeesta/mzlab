# Privacy

- **I tuoi file non lasciano il computer.** Tutto il calcolo avviene nel browser (o nell'app desktop): i file `.mzML`, i disegni e i risultati non vengono inviati a nessun server.
- **Nessun account, nessuna analisi dei visitatori.** mzLab non usa cookie di tracciamento, statistiche d'uso né servizi di terzi: la pagina può collegarsi solo al proprio sito (lo impone la politica di sicurezza della pagina).
- **Cosa resta nel browser**: sessione, disegni, progressi e, per i file grandi, una copia dei file e dei loro indici nello spazio del sito (IndexedDB, archivio del browser e memoria della pagina). Resta solo su questo computer e questo browser. Per toglierlo: il pulsante **«Reset completo…»** nelle impostazioni, oppure i dati del sito nelle impostazioni del browser. Su un computer condiviso, cancellalo a fine lezione.
- **Chi ospita il sito**: il sito è su GitHub Pages; come per ogni sito, GitHub può registrare l'indirizzo IP di chi lo visita (vedi la [informativa di GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)). Il progetto non vede questi registri.
- **App desktop**: l'unica connessione è il controllo degli aggiornamenti verso il sito ufficiale; i file sono letti dal disco e non vengono copiati altrove.
- **Segnalazioni**: nelle issue pubbliche **non allegare dati di laboratorio né dati personali**.

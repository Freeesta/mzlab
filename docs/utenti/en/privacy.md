# Privacy

- **Your files never leave your computer.** All the calculation happens in the browser (or in the desktop app): `.mzML` files, drawings and results are not sent to any server.
- **No account, no visitor analytics.** mzLab uses no tracking cookies, usage statistics or third-party services: the page can only connect to its own site (the page's security policy enforces this).
- **What stays in the browser**: session, drawings, progress and, for large files, a copy of the files and their indexes in the site's storage space (IndexedDB, browser file storage and page cache). It stays on this computer and this browser only. To remove it: the **"Full reset…"** button in the settings, or the site data in your browser settings. On a shared computer, clear it at the end of the lesson.
- **Who hosts the site**: the site is on GitHub Pages; as with any site, GitHub may log the IP address of visitors (see [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)). The project does not see these logs.
- **Desktop app**: the only connection is the update check towards the official site; files are read from disk and not copied elsewhere.
- **Reports**: in public issues **do not attach laboratory data or personal data**.

# Verification of Gemini's loading-path reviews: lot 3 (frontend JS, `mzlab/web/`)

Phase 1: read-only, same method and legend as `gemini-caricamento-verifica.md` (T = true, P = partial, F = false). The cloud has no browser, so nothing here was run: verdicts come from the code, with the visible behaviour spelled out. The real lines are cited (Gemini's are off by ~115 in `shell.js`). Speed rows say what to measure.

## In brief

- 23 items (E12 split in a/b/c): 10 T, 11 P, 2 F (E1 and E9 count as T for the premise; all nine speed items are P). Real and visible: **E2** (a generic load error leaves the full-screen veil up), **E3** (after F5 with a saved session, "Add files" shows "Restoring session…" instead of the drop box), **E6** (a re-dropped `.wiff` pair is read again when its samples have DATA names), **E7** (the 3rd same-named raw/wiff silently overwrites the 2nd).
- **E1** is a real code defect (the loop sits after `//`) but has no visible effect today: nothing reads `role/sub/tconf` back from `/api/session`, and the Python reference does not carry them either (so Gemini's "parity broken" is wrong). The fix adds JSON keys to the session: check that no byte-parity test compares it.
- Wrong or risky fixes: **E4** (b) (rebuilding every slot costs 0.15 s per file, and the real problem is the index shift, which neither version solves), **E9** (re-arming in `clear()` can delay the series list by 3 s), **E10** (`continue` would evict the *newest* entries), **F1** (the engine is one thread: `Promise.all` pipelines messages, not work), **F4** as written (completion-order `out.push` changes which duplicate gets the folder suffix), **F5** (`body.cancel()` would stop the warming), **F7** (modules are already fetched in parallel), **F8** as written (`__proto__` bypasses the substring test), **F9** (the `<pre>/<code>` skip changes what the user sees).
- Needs Federico: **F5** (first-paint warms the 8.7 MB Ketcher bundle on slow links, against the 8/10 policy in `shell.js:476`: a default), **E3** second half (should the "Add files" table list the files already open after F5?).
- No `ottimizzazioni-tentate.md` entry covers any of these (grepped: parallel, prefetch, ketcher, reviver, lr_entry).

# Tabella delle transizioni di un triplo quadrupolo (`chrom.transitions@1`, `crates/mzlab-feat/src/transitions/`)
Aree vicine: `wiff.md` (canali SIM `SIM SIC Q1=`), `liste.md` (editor `flow/liste`), `cli-passi.md`, `wasm-tetti.md` (`flowtab`).

- Cosa fa: per ogni campione e ogni riga di una tabella di ioni SIM (solo Q1) o transizioni MRM/SRM (Q1>Q3) trova il cromatogramma della riga e integra il picco in RT ± finestra con `mzlab_core::peak1d::find_peak` (`legacy::lr::peak1d` lo riesporta; nessun secondo integratore). Le righe senza RT danno solo candidati, mai un'attribuzione di isomero.
- Tabella = dati, mai codice: un CSV modificabile (parametro `transitions`, `x-liste` = `transitions`), salvato nel piano e nella sessione, modificato dall'editor delle liste (`flow-liste.js`, solo app). Intestazione obbligatoria che comincia con `name`; colonne `name;q1;q3;polarity;rt;rt_window;isomer_group;note;formula;adduct` in qualsiasi ordine (`table.rs`, `HEADER`). `to_csv` riscrive le celle come scritte (`;`).
- Righe: `q1` scritto, oppure calcolato da `formula` + `adduct` con `mzlab_core::elements` (mai un numero nel codice); addotto predefinito `[M+H]+` o `[M-H]-` dalla polarità; polarità vuota = quella dell'addotto, altrimenti `+`. Virgola decimale letta come punto se il separatore non è la virgola. Errori per riga `error.liste.*` (`noName`, `badPolarity`, `badAdduct`, `badMz`, `noMz`, `badFormula`, `badRt`, `twice`, `noHeader`, `badColumn`).
- Canali (`traces.rs`): i cromatogrammi `srm` di `mzmlhead` (anche SIM, `q3` assente) letti con `TracceMzml::cromatogramma`; polarità dal testo dell'id (`polarity=positive|negative`), assente = vale per entrambe. `srm::leggi` e i byte MRM esistenti non cambiano.
- Abbinamento (`text.rs`): Q1 entro `mz_tol` (0,5), Q3 entrambi assenti o entrambi entro `mz_tol`, stessa polarità; vince il più vicino, a pari distanza il primo. Una riga SIM non prende un canale SRM e viceversa.
- Esiti per riga e campione (`peak`): `ok`, `edge` (apice sul primo o ultimo punto della finestra), `no_peak` (sotto `snr_min` o `min_points`), `no_trace` (nessun canale), `no_rt`. Solo `ok` ed `edge` contano in `n_peaks` e nelle medie.
- Uscite (parametro `output`, un solo file per istanza): `peaks` (lunga: campione, riga, apex_rt, area, height, snr, fwhm_s, peak), `table` (una riga per transizione: `area <file>`, `apex_rt <file>`, `n_peaks`, `rt_mean`, `rt_sd`), `candidates` (solo righe senza RT: picchi del canale in tutti i campioni, raggruppati per distanza di RT ≤ `group_rt`, ordinati per area massima; un fianco non è un candidato). Esportazione CSV = il file stesso.
- Preset `example_1` (`data/transitions-example-1.csv`): 14 prodotti di trasformazione da formula + `[M+H]+`, senza RT; si applica solo se scritto (`--set tr.preset=example_1`). Le formule di BQM (C15H12N2O2) e BQD (C15H10N2O3) sono quelle della letteratura dell'ozonazione (m/z 253 e 267). Il nome del composto non compare in codice, id o interfaccia.
- Parità: un solo testo `transitions_text` (CLI `flow_transitions.rs`, `Exec::File`) e `transitions_packed` (browser, `flow_transitions` di `flowtab`, file impacchettati con manifest `[{name,len}]`); `flow-web-transitions.js` blocca con `platform.computer` se una sorgente non è un mzML aperto in Dati o se i file superano 128 MB. Nel browser un `.wiff` va prima esportato in mzML; CLI e app: `convert.mzml` → `chrom.transitions`.
- Prove: `transitions/tests.rs` (canali sintetici come `tools/wiff_sim.py`), `flow_transitions_tests.rs` (`.wiff` SIM → mzML → `flow run`: byte = `transitions_text`, isomeri 2,5/4,0 min, ione negativo, preset e candidati, `transitions_packed` = CLI), `e2e_flow_transitions.py` (browser = `flow run` byte per byte per le tre uscite).
- Tabella SIM di Dati (`simtab::table_text`, `sim-tabella.js`, carta `#simtab`): con file di transizioni aperti (kind `mrm`), ogni canale SIM (transizione di `/api/mrm` senza Q3) di ogni file integrato su tutta la traccia da `peak1d::peaks` (lo stesso dei candidati di `chrom.transitions@1`: lisciatura 3, almeno 3 punti, S/N ≥ 3, fino a 10 picchi per canale, isomeri come picchi distinti). Nessun canale SIM = `err.simtab.noChannel` e la carta resta nascosta.
- Tabella SIM, uscite (`simtab::OUTPUTS`): `peaks` = una riga per picco (campione, Q1, nome, n., RT apice, area, altezza, S/N, FWHM; canale senza picchi = n. 0); pivot `area_sum` (somma delle aree, predefinita), `area_max`, `height_max`, `apex_rt` (del picco più grande), `n_peaks`, con `layout` `samples` (righe = campioni nell'ordine di caricamento, colonne = Q1 o `transition=N`, `#k` per canali ripetuti) o `channels` (scambiato). Bianco = 0,0 e 0 picchi; canale assente nel file = cella vuota.
- Tabella SIM, colonne e gruppi: una colonna = un m/z (Q1 a 0,01) in tutti i file, intestazione = solo il m/z; un canale senza Q1 = `ion N` (posto nella lista da 1, «ione N» nella pagina), tenuto a parte per gruppo (`ion N [gruppo]`), così due liste senza Q1 non si fondono se raggruppate. File con `group` (gruppi laterali, `f.ugrp`): righe per gruppo nell'ordine di `E.ugOrder`, poi i file senza gruppo, colonna `group` dopo `sample` (non in `channels`); nella pagina riga di testata richiudibile per gruppo. Aree e altezze in `numfmt::sci` (`7.84077E+04`).
- Tabella SIM, grafico nel tempo: il pulsante grafico di una colonna (riga in `channels`) la mette nel grafico (`QAQC.chart` con `xs`): x = «Tempo» della tabella dei file nell'unità scelta, y = valore scelto (la somma delle aree per la tabella dei picchi), una linea per colonna e gruppo (colori `PAL`), bianchi tratteggiati grigi (senza tempo = livello medio su tutto l'asse); senza tempi una riga d'avviso; tabella dati con «Dati del grafico» e il tasto T.
- Tabella SIM, parità: sito `api/simtab?k=..&output=..&layout=..` (`rust-bridge-info.js`: `mrm` di ogni slot, poi `sim_table` di `mzlab-wasm`), app op `simtab` di `rpc.rs`, CLI `mzlab-cli sim-table FILE... [--set output=..] [--set layout=..] [--set group.CAMPIONE=GRUPPO]... [--out PATH]` (`sim_table_cmd.rs`: file del fornitore da `lettori_mzml::guscio`, nomi come `conversione.js::wiffName`; campione tagliato = avviso su stderr e punti prima del taglio). CSV scaricato (`sim-table-<uscita>-<layout>.csv`, riga di provenienza in testa) = uscita della CLI.
- Tabella SIM, prove: `simtab_tests.rs` (coppia di isomeri a 25 s, bianco, `ion N`, layout, colonna per m/z in file diversi, gruppi), `sim_table_cmd_tests.rs` (`sim3` di `tools/wiff_sim.py`: picchi entro 0,014 min dal vero, `.wiff` = suoi mzML byte per byte, copia tagliata al 60 %, `channels` elenca i canali SIM), `e2e_sim_wiff.py` (pagina = CLI byte per byte per cinque viste e i CSV scaricati; log di msconvert saltato con nota; copia tagliata), `e2e_sim_gruppi.py` (`sim_senzaq1` + `sim_listab_senzaq1`: senza gruppi «ione 1» unico, con i gruppi List A / List B colonne separate = CLI con `group.`; `H2O` ruolo Bianco; grafico nel tempo con i tempi dei nomi).
- Interfaccia SIM (`sim-ui.js`, `window.SIMUI`): un file `mrm` con transizioni senza Q3 ha `f.sim` = numero di ioni (da `api/mrm`; per un file «empty» dai canali `sim`). Cella Esperimento «SIM · N ioni», gruppo laterale, titolo `@sim`, pulsante `#np-mrm`, selettore (`canali.js`, famiglie `srm` e `sim`) e riga `#simhelp` (con pulsante alla tabella) parlano di ioni SIM; il pulsante «Area» (`p.area`, default attivo) riempie le tracce con una tinta del colore.
- Canali SIM senza Q1 (il lettore dà solo `transition=N`): omologo `sim|1|#N|pol` e chiave `iN` (posizione nell'esperimento, `SIMUI.chKey`/`trKey`) al posto del m/z; etichetta «ione N» (`canali.sim.ion`), mai «null»; tabella del pannello Metodo senza colonne Q3/CE e con «—» (`SIMUI.methodTable`); avviso oltre il tetto di file «file SIM» (`mrm.capNoticeSim`). Con il Q1 le etichette tornano il m/z. Prova: `tests_e2e/e2e_sim_senzaq1.py` (`sim_senzaq1.wiff` di `tools/wiff_sim.py`).
- Ioni SIM, colori e menu: un colore per ione (`SIMUI.color`, indice sull'unione degli ioni dei file), uguale in ogni campione. Il menu del cromatogramma ha «Estrai ione ›» / «Estrai transizione ›» (azione `mrm.estrai` con `sotto`, sottomenu di `menu-sotto.js`: pallino colore, spunta, «Tutti»; clic = solo quello, Ctrl/⌘ aggiunge o toglie, Maiusc prende l'intervallo) al posto di XIC.

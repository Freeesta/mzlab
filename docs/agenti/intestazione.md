# Header and loading table

- **Fullscreen**: `#fs-btn` (Fullscreen API with `requestFullscreen({navigationUI:'hide'})`, `aria-pressed`, `header.fullscreen*`); on `fullscreenchange`, also with Esc, the `.fs-in` icon becomes `.fs-out` and the title "Exit fullscreen (Esc)". Hidden without the API (iPhone). In `:fullscreen` `--fs-top` (14 px) adds margin above the header: on macOS the menu bar appears at the top edge and a page cannot disable it (Pointer Lock hides the cursor, Keyboard Lock changes Esc). Test: `e2e_schermo_intero`.
- **Header button focus** (rules `header button:focus-visible` in `app.css`): 2 px ring only from the keyboard, drawn INSIDE the button (`#stbar` has `overflow:hidden` and would clip an outer ring), never the browser's double ring; after the mouse no ring (`:focus:not(:focus-visible)`). Test: `e2e_focus_intestazione`.
- **Movable "almost fullscreen" window**: on the web there is no way to have it without the tab bar. `window.open` with `popup`/`width`/`height` opens a window with the browser bar.
  Document Picture-in-Picture accepts only content already in the page, not the whole app. The Window Management API (`getScreenDetails`) is Chromium only, needs a permission, and does not remove the bar. Only the Fullscreen API removes it.
- **Logo** (`logo-piccone.js`, loaded from the list `L`; `tests_e2e/e2e_logo_piccone.py`): each hit (click or Enter/Space, the logo has `tabindex=0 role=button`, alt and title unchanged) makes an SVG pickaxe strike and shakes the logo, with 4 stages of cracks; with no hits for 3 s the cracks close.
  The 5th hit breaks the logo into 6 shards and makes it GOLDEN (`html[data-logo-gold]`, localStorage `qqq.logo.gold`), the next round gives back the original logo (alternation); it switches nothing on or off. In the dark theme the gold is brighter (contrast ≥ 4.5:1 on the header). With `prefers-reduced-motion` or `data-a11y-reduce`: only the crack stages, no shake or shards.
- **(i) button** (`help.header.body`): three paragraphs (free and open source, version in progress, mailto address for suggestions), with no title or other links. "More" opens PubChem and BioTransformer in another tab, with no boxes.
- **Loading area** (`#start`, up to 1240 px wide): the `load.drop` text (.mzML, .raw, .wiff, .D folders) is the final one from the first drawing. The "Full reset" has no row of its own: it is in the "New session" dialog (header, visible from the first drawing) and in the start timer button (`ldArmBootTimer`). In the header the icon-only buttons (`#sb-toggle`, `#fs-btn`, `#bug-btn`, `.hq`) are visible also during `i18n-wait`.
- **Loading, details**: the `#cartinfo` row ("Folder …: n files to load") disappears when loading is done. The `.prog i` bars move with a 0.35 s transition (not with `prefers-reduced-motion`). In the `renderFiles` table the group bar has `colspan = ncol` (7 columns + Conc.), the concentration does not repeat the header's unit.
- **Loading, icons**: the method field is a thin row without a box (`.card.method-row`, step title only for screen readers, `#dropdam` with "+ Add the acquisition method (optional): drag it or browse", drop target and file picker anchor).
- **Loading, ring**: the loading screen (`#ldmsg .ldic`) and the progress panels (`.convprog .cp-head`) show a spinning ring (still with reduced motion or `data-a11y-reduce`); the common panel finished without errors shows a tick (`.cp-done`). Test: `e2e_carico_icone`. "Download mzML" and the × sit on one row (`white-space:nowrap`).
- **Experiment type in the table** (`mixedText`, `expCell` in `shell.js`): a file with several parts shows the part names joined by " + ", with no polarity or number of precursors; Full Scan + MS2 = "Full Scan + DDA"; alternating polarity alone is a "Full Scan". Test: `tests_e2e/e2e_misti.py`.
- **Informational notices that stay on screen** ("Files stay in the browser" note of `reset.js`, new-version notice of `aggiorna.js`): `avvisoAuto(el, {ms, x, onClose})` in `explore.js` removes them by itself after 20 s; the timer stands still while the pointer is over the notice or the focus is inside, and an X (added if missing, `avviso.close`) closes it at once. Notices that ask for an action do not use it. Test `e2e_mappa_mirino_maiusc`.
- **Warning/info/error/success boxes**: class `.avv` (+ `warn`, `bad`, `ok`; no variant = info) in `app.css`, colours from tokens only (`color-mix` on `--warn`/`--bad`/`--ok` and `--panel`), text `--ink`: contrast ≥ 4.5:1 in light and dark theme; no hand-written light backgrounds. Test `e2e_contrasto_avvisi` (contrast of each variant + axe `color-contrast` on the "Acquisition method" window).
  - `tests/test_contrasto_temi.py` computes the token contrast in light, dark and high contrast and rejects invented variables (`--fg`, `--border`): use only `--ink`, `--line` and the other tokens of `app.css`.
- **Report a bug** and **Suggest an improvement** (two plain buttons in the Settings panel, `#uip-bugbtn`/`#uip-g-bug` and `#uip-sugbtn`/`#uip-g-sug` with the form in `#uip-bug`/`#uip-sug`, no button in the header; lazy `import()` from `settings.js` on first click):
  - Modules: `bug-report.js` (`mount(host, kind)`, kind `bug|suggestion`), `bug-report-testo.js` (pure, tested by node), `bug-report-dati.js` (reads the page). The `#bug-what` / `#sug-what` field (the suggestion also has "What I was doing", `#sug-doing`, optional) and the diagnostics as a list of keyed FIELDS (`campiDiagnostica`), each with its own checkbox in the "What is included" `<details>`: the user unticks it and the field leaves text, link and JSON.
  - Never file names, sample names or paths: every string goes through `anonimizza` with the session's names.
  - Bug fields (keys): `version` `date` `ua` `mode` `view` `lang` `screen` `device` `isolated` `opfs` `engine` `tool` `cards` `files` (number, formats, size class of the total) `settings` (only the `UIP` names that differ from `UIP_DEFAULT`) `sw` `storage` (counts and sizes, never the keys).
  - Other fields: `errors` (last 20 with frames reduced to `function script.js:line:col`; every other file `<file>`, no query) `actions` (last 15 clicks: `ERRORI.azioni`, static ids only, never text). The suggestion has only `version` `view` `lang` (`TIPI.suggestion.keys`). Fixed headings: `## Suggestion`, `## What I was doing`, `## Diagnostics`.
  - "Copy" = clipboard; "Send by email" = `mailto:` to Federico, with the address composed only on click (`urlEmail`, ≤ 1900 characters, longer is cut with a notice); "Download full report" = `.json` (`jsonRapporto`, schema `mzlab-bug-report/1` or `mzlab-suggestion/1`, the same keyed fields: the form for agents and attachments).
  - "GitHub" = `<a target=_blank>` to `issues/new?template=<bug|suggestion>.yml&labels=<bug|suggestion>&title=…&<cosa|idea>=…` (`TIPI`; the `.github/ISSUE_TEMPLATE/*.yml` forms fill the fields by id; `labels=` only works for those with triage rights, the real label is set by the form and must exist in the repository), ≤ 6000 characters (longer is cut and the screen says so: "Copy" or the download carry everything).
  - No network from the site to GitHub: a user click opens the form, nothing starts by itself (a static site cannot hold a token). The engine answers `api/provenance` for the version. The CLI has no report route: the desktop app uses the same panel. Tests: `tests/test_bug_report.py`, `tests_e2e/e2e_bug_report.py`.
- **Narrow screens** (≤600 px, without the phone tab): the header is on two rows (logo, tabs, gear, (i), fullscreen and report above; tools and "New" below, `#stbar` with 150 px basis to wrap) and the controls are at least 28 px (rules at the bottom of `app.css`). Test: `e2e_intestazione_stretta` (400 px: header ≤ 80 px, nothing off screen, no target < 24 px).
- **Leaf of the empty states**: a single `svg.leaf` in `#fl-hint` (`index.html`), 72×44 px, `aria-hidden`; `window.EMPTYLEAF(key)` (`barra.js`) clones it with an `empty.*` row for lists, losses and adducts. With motion allowed `leaf-fall` falls only once (9 s, only transform and opacity) and stays visible on the ground; a repeated rendering of the same row (class `rest`) shows it already still, with `prefers-reduced-motion` or `data-a11y-reduce` it stays still, paused when the panel is hidden; tests `e2e_foglia*.py`, `tests/test_foglia.py`.
- **Header tour** (`tests_e2e/e2e_giro_intestazione.py`, in the Chromium Linux `--fumo` round, ~75 s): on Data, Drawing, Flow and Tabui, without samples and with one, every visible header button opens something (window, menu, panel, fullscreen) and Esc or a second click closes it; no main block (header, `#stbar`, `#sb-pane`, `#tools`, `#v-workspace`, panels) moves by more than 2 px; Data → another view → Data leaves everything as it was; no console errors.
  Outside Data, Calculator, Adducts and losses and Lists open their windows (`toggle()` in `barra.js`). Full measurement (CLS, memory, requests): `tests_e2e/audit_pagine.py`.

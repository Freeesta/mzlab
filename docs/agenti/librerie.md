
- `scores.rs` (contributi): `entropy_contributions`, `cosine_contributions`, `modified_cosine_contributions` danno `(m/z del picco, contributo)` per ogni coppia abbinata; la loro somma è il punteggio (entropia, coseno, coseno modificato) entro 1e-12. `spectra.match` con `score_terms` li scrive come record `score_terms` (`mzlab-core::score_terms`, `docs/agenti/livelli.md`). Prova: `tests/score_terms.rs`.
- Filtri del passo `spectra.match` sulle voci di libreria (`flow_match.rs`: `meta_filters`, `passes`): `name_contains`, `adduct_contains`, `instrument_contains`, `ce_contains` tengono le voci il cui nome, addotto, strumento o energia di collisione contiene il testo (maiuscole ininfluenti, si combinano, non valgono per `tree`). Prova: `metadata_filters_keep_the_matching_entries`.
- Tempo di ritenzione delle voci: `Spectrum.rt` (minuti, `Option`), letto da `parse.rs` (`rt_minutes`: chiavi `RT`/`RetentionTime`/`RTINSECONDS` di MSP, MGF, JSON e `AC$CHROMATOGRAPHY: RETENTION_TIME` di MassBank; unità «s» = secondi) e scritto nel `.mzlib` come `f32` nei byte 28..32 del record degli spettri con `FLAG_HAS_RT`; lo stesso formato v1 (i file senza RT hanno zeri e flag spento), `SpecRec::rt_min()` lo legge. Il passo `spectra.match` con `rt_tol` (min, 0 = spento) scarta le voci a più di `rt_tol` dall'RT dello spettro cercato (voci o spettri senza RT restano) e scrive `rt_delta_min` (cercato meno libreria). Prove: `tests/retention.rs`, `rt_tol_excludes_entries_by_retention_time`.

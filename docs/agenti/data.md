# Data view, low resolution (`explore.js` and companions)
File map (classic scripts in `index.html`, in this order, shared global scope; each function lives in a single file): `explore.js` = colours, start-up veil (`#loading`) and `#busybar`, notebook, data with cache and loading/file list, file bar, windows and menus; `pannelli.js` = floating panels (placement, dragging, tabs, names and metadata of images/Excel, `XIC_BELOW`); `grafici.js` = plot drawing (chromatograms, corrections, zoom, `drawMap`); `picchi.js` = peak integration, spectra, `contMarks`;
`eventi.js` = mouse and keyboard on the plots, acquisition method, toolbar, formula → m/z calculator; tooltip `#qtip` in `tooltip.js`.
The core is in CLAUDE.md.

## Loading
- Box 1 = data files (from the CONTENT; the name gives only type/time/concentration, in yellow if guessed; formats written once in small type, `.fmts`; next to the title there is no "?": the warning on `.wiff.scan` and `.D` folders appears only after the drop if the `.wiff.scan` is missing), box 2 = "Drop the method file here" in a compact row (`#dropdam`, several files, Enter/Space; formats read in `METHOD_FORMATS` of `shell.js`, one row per format, from which text and filter come); each method is a chip "Method: name" with × (`renderMethods`);
  in the Method window the method with the same base name as the data file wins (`App.method`), then the one by type and differences; an unrecognised file goes into the single warning (`e2e_metodo`, `tests/test_metodo_nome.py`) (if of a different type from the files `#methwarn` appears, `/api/method_warnings`: MRM is decoded from the file, Full Scan/MS2 only from the method NAME).
- **A single warning per load** (`upload()` → `reportLoad()` in `shell.js`, `#unopen`, the only `aria-live=polite`): files of a recognised instrument format that cannot be opened (single table `formati-noti.js`, lazy, `FORMATI_NOTI.classify`: vendor, format, `read`/`unsupported`) give one row per format ("SCIEX .wiff2: recognised, not yet supported"; the `read` ones that the browser did not open: "convert it to mzML") and a collapsible list of names (5 + "and N more").
  Files that are not known mass spectrometry files (unknown format), identical read errors and files moved between boxes are one row per type.
- **Folders**: pointed folder (`cartella-puntata.js`) or one-off (`cartella-carica.js`), details in `docs/agenti/data-folder.md`.
  Warnings are deduplicated per session (`mzlab.unopen`); "How to convert" guide `<details id="convhelp">` (once per session, `mzlab.convopen`). Where the engine converts `.raw` files (desktop) the guide opens only if needed. Test `e2e_converti`.
- "Try the example files ▾": Full Scan (5 files), MS2 (2), MRM (4 standards), HRMS (4 Orbitrap DDA, opens in high resolution); only the chosen group is downloaded, on click: the group's rows are in the list at once, the download is the first 40 % of the bar; after "Cancel" nothing opens.
- Loading screen (`#loading`): at engine start peak bars (`.ms`), while data load (`window.qqReady` true) three ions drawn as a dot with a trail (animation `base`; the `an-*.js` analysers are off, `docs/agenti/analyzers.md`);
  centred above the phrases (`#ldion`, `ldIon(on, mode)`; colours `--accent`, `--ok`, `--bad`, electrodes `--line`; a still frame with reduced motion). Phrases (`PHRASES`, `ldNext`) and `ldIon` live in `avvio.js`: do not move them to `explore.js`.
- A single status line in the start-up veil (`#loading`, `#ldmsg`, `ldRefresh()` in `avvio.js`): the start-up phase (`window.qqPhaseCur`, keys `load.step.*` from the worker) or the text of `loading(true, msg)` replaces the phrases; no bar: the percentage, if known, is text in the line (`role=status`, `aria-live` active only during a phase, `aria-busy` on `#loading`). Resume of saved files (`rust-worker.js`): `onblocked` → `load.blocked`; 30 s without progress (`?ripresa=ms` in tests) → error with "Start over".
  Start-up banner and the 10 s button (`qqHardReset`, `browser.js`; ignores a second call) run `QQRESET.run("all")`: the same "Full reset" as the `QQRESET.ask` dialog of "New session", saved libraries included, then `?riparti=1`. Test: `e2e_avvio`.
- **File order and time** (`ordine.js`, pure functions tested by `tests/test_ordine.py`; `e2e_ordine`): the order is decided over the whole list, in one place (`fileComparator`/`orderFiles`): by increasing time if the names give a time (mixed units already converted to minutes by `project.py`: min, h, days), otherwise by increasing concentration (converted to mg/L), otherwise natural alphabetical (file2 before file10); ties by name. The load table applies it within experiment and type (`sortFiles` in `shell.js`).
  Times are always in minutes; the unit shown (min, h, d: `tunitGet`/`tunitSet`, `mzlab.tunit`, `fmtTime`) is the menu in the header, always present. Time and concentration fields: `type=text` `inputmode=decimal`, comma allowed, a non-numeric text gives `aria-invalid`. A `.raw` is read like the name of its mzML (`guess_sample`, same name without extension).
- **File list in HR** (`renderFileList` in `explore.js`, groups from `hrGroup` in `ordine.js`; `e2e_lista_hr`): on first load in HR only the first file opens (list order; the parts of a DDA count as one file), the others stay in the list and a click on the row opens them (they are added).
- **Label of mixed files** (`partLabel` in `explore.js`; `e2e_etichetta_tipo`): the parts of a mixed file are called Full Scan, DDA, MS2 or MRM (polarity stays); the key `x.mzML#MS1` does not change; the engine writes the label (see Pitfalls).
- **Extract the MS2 scan** (`ms2OfPeak`/`extractMs2` in `eventi.js`; `e2e_estrai_ms2`): right click on the label of a peak of an LR Full Scan spectrum whose m/z (±0.6) is the precursor of an open MS2 file → opens the spectrum of the scan nearest in time.
  Groups: "Full Scan" (also DDA: ONE row that opens MS¹ + MS²; no "DDA" group; scans without precursor), "MS2 (Product Ion)" (only scans with a precursor), "MSn infusion" (`infusion`: ONE element, tree in `infusione.js`); user groups: `groupFiles` (`lista-file.js`; field `ugrp` in `ui.files`). Compact list (`flCompact`: `pointer:coarse` or window <= 1100 px, HR only): lower rows (CSS in `app.css`) and groups that fold, memory in `mzlab.flgrp`.
- **Progressive opening**: details in `docs/agenti/data-loading.md`.
- **From the first file shown to the workspace**: hidden plots are not prepared (`setup` only with `#v-data` visible); the first visible TIC is the provisional one from indexing (`tic-provvisorio.js`, `getChrom`; `chrom-primo.js`: a single `api/chrom` request per chromatogram, even with several redraws) and `api/chrom` starts before `api/metodo` (`CHROM1.ready`, awaited by the series list of the registry in `registro-serie.js`). Test: `e2e_area_senza_sprechi`; measures: `e2e_area_lavoro_misure`.
- Progress bar (`#busybar`, in `explore.js` after `loading()`): `window.fetch` is wrapped, and every `api/...` call still running after ~1 s shows it (hidden under the start-up veil); no animation with reduced motion.

- **Peak table**: `Run.table(level, polarity)` is a view on the file's `.mzidx` (format in `docs/agenti/mzidx.md`), built on first request and reopened without rereading spectra; XIC, TIC, map and spectra read slices (`PeakTable.iter_chunks`, `sum_by_scan`, `base_peaks`), memory stays flat. Index folder in the dev server: `$MZLAB_CACHE` (default `~/.cache/mzlab`; tests use a temporary one).
  On the site files and indexes live in OPFS (see `mzidx.md`); the gear has a single button to remove them, "New session" in the header (window with "Full reset" and "Files"); "Remove from session" on a file also removes its OPFS copy and its indexes (`removeFile`, `lista-file.js`).
  `lista-file-menu.js`: right click on a file (`fileCtx`) and quick selector of a plot (`fileMenu`). **User groups** (`lista-file.js`, LR and HR): with 2+ files ticked "Group files" creates "Group N" at once (first free N; never MRM in the bench); a file is in a single group, which replaces its automatic header (`grpOf` → `u:<name>`, `ugHead`). Header: double click or F2 renames; menu (right click, Menu, Shift+F10) Rename / Ungroup / Remove group (`removeAllFiles(fs, name)`). `ugrp`: session, undo of `files.view`, label in the metadata table.

## Tabs and plots
- **Single view**: no tabs and no "Times and experiments" button (do not reintroduce). Full Scan / MS2 / MRM each have their own block of plots on the same page (never mixed plots; `tabs.js` `ensureBlocks`, `stackBlocks` for sessions saved with one tab at a time); the file list has one group per type (count, tooltip of the Q1→q2→Q3 scheme). `E.tab` = type of the current file: a click on a file of another group (`goToFileTab`) sets it and brings you to its block (`scrollToBlock`); toolbar buttons follow the types that have files (`toolbar()`).
- **Initial view**: TIC + spectrum at the apex (+ MRM); DDA/IDA: trio in a column (chromatogram, Full Scan MS1 at full width, MS2 below). Test `e2e_tutti`.
- **Labels next to the file name** (`renderFileList`, explore.js): a blank or standard file carries the tag "blk" / "std" (`typeTag`, keys `files.type.*`, the full word in the `title`; for MRM standards the concentration follows);
- **File list, rows**: names do not show the extension and are unique ("(2)", `noExt`/`uniqueLabels`, `lista-file.js`); precursor rows show only the number (tooltip "Precursor m/z", `files.prec.row`); the time "N min" only on Full Scan rows; never the word "Profile"; an experiment with `chiuso: true` in `esperimenti.js` (the product ion) starts closed.
- **File list, groups**: `ugArrange` (`lista-file.js`) sorts groups like `ordine` in `esperimenti.js`; "None" = `E.ugBy={by:"flat"}`; the panel closes with `#sb-toggle` (the × `#sb-x` only in the sheet).
- **Chromatogram**: click = spectrum of one scan; drag = interval (average spectrum); double click/tap or Enter INSIDE the interval = its average spectrum (`chrom.avgSel`, beats the zoom; the 1st click removes it, the double click puts it back, `p._dsel`; `e2e_intervallo_spettro`); outside does the usual; right click = spectrum in a panel, XIC, integration, annotation. After a click ← → one scan (held down they scroll), Shift jumps of 5,
  Space auto-scroll (same pace and same `stepScan` as the held arrow key: `paceDue` in `scroll.js`), Esc stops it. **Cursor**: the line of the current position moves with the click and by dragging it on the plot and with the arrows (one scan, Shift five).
  Only with finger or pen it has a dot at the top (`.clh`, `role=slider`, `aria-label`, `p.ch`, drawn by `cursorLine` in `scroll.js`, handled in `eventi.js` with `moveCur`) to drag: shown by `(pointer: coarse)` or the class `ptr-touch` on the root (the last pointer used, `touch.js`; `ptr-mouse` hides it on the first mouse move, even on a touch laptop). Trackpad: pinch or Ctrl + wheel = time zoom, two fingers sideways = scroll of the zoomed time.
  If the window of the linked spectrum contains no scans of the type shown (DDA, MS¹/MS² filters) `snapNearest` (`picchi.js`, `/api/nearest_scan`) picks the nearest (on a tie the previous) and snaps the cursor; "No scan in this interval" stays only for a file without scans of that type.
- **Overlaid TICs**: click, arrows and Space act on the file selected at the side (`nearestFile`, `stepScan`), not on the highest one; the linked spectrum shows that file only; its menu lists only the ticked files and the choice (`kSet`, held by `pushLinked`) stays until another file is chosen, a TIC trace is clicked (`pickTrace`) or the tick is removed (`drawSpec` switches to the first ticked). Tests: `e2e_tic_file_attivo`, `e2e_spettro_file`.
- **XIC**: window `openXic` (<=10 ions, m/z or formula + adduct; "No adduct" = `adduct=none`) and right click. LR (`prof1.hr` false, `HR.isHr`): [n−0.2; n+0.3], n = nearest integer (`xicWin`, default window: `xic-discard.md`). HR: ppm of the profile (5 FTMS, 10 TOF). "XIC" button: `fast-viewer.md`.
- **MS2 transitions** (low resolution): the chromatogram of the MS2 tab has the menu `data-o="tr"` like the MRM panel (none / all / one precursor > fragment pair); the list comes from `/api/ms2tr` (`ms2_transitions` in `explore.py`: per precursor the 5 fragments, 1 Da cells, with the most intensity, numbers only), the trace is the ±0.5 window of the fragment in the scans of that precursor only (`ms2trSeries` in `grafici.js`, row `p._trs` as for MRM); tests `tests/test_ms2_transizioni.py`, `e2e_ms2_transizioni`.
- **Integration** and **peak detection** (automatic tool, manual, table, parameters, high resolution): `docs/agenti/data-integration.md`.
- **Spectrum**: m/z axis fixed on the level's interval, lock only on y (in the panel bar), ruler (snaps to the nearest m/z label within 34 px; cancelled if m/z zoom, scan, file or level change), annotations, isotope profile of a formula from the right click (a formula with a trailing `+`/`-` is the ion as it is; changing the zoom turns the profile off), library search for MS2.

## Site, page and smartphone (details)
- **On the site**: `tools/build_site.py` copies `mzlab/web` into `site/static`, writes title and Open Graph tags and the service worker `sw.js` (details in `service-worker.md`). No Python on the site, mzFinder included: `build_site.py` stops if it finds `pyodide*` or a zip with `.py`.
  `browser.js` passes `fetch("api/...")` to the Rust/WASM engine (`rust-bridge.js`, `rust-worker.js`, `lr.js`); mzML files and their `.mzidx` live in OPFS (`archivio.js`, Rust workers only, `docs/agenti/mzidx.md`) and the notebook in IndexedDB. Loading: at once only the engine, then when idle whatever is under 1 MB (OpenChemLib), Ketcher on hover over "Drawing", examples only with the button. An engine that dies twice in a minute stops the page with `error.engineFallback` ("reload"). `docs/agenti/rust.md` and `rust-routes.md` hold the route inventory.
- **Spectrum ruler** (`spettro.js`): the label of a measure is "Δ" + *m/z* in italics + number, or, if the difference is an adduct exchange (`adductPair`, list `AD_PAIRS`, tolerance 0.5 / 0.003 in HR, positive or negative by file polarity), the short symbol ("Na⁺/H⁺") with the full form in the tooltip. It is a target in `p._a.lbls` (`dm`): right click opens Neutral losses or Adducts (`dmOpen`, also used by `mappa.js`) instead of the menu.
- **Two-step actions** (second peak of the measure, second segment of the internal blank): `pendKey(p)` in `eventi.js` gives the i18n key (`pend.*`) of the label at the cursor (`pendHint`, in `#qtip`) and Esc removes the first step; a new two-step action adds a branch to `pendKey`.
- **Page** (`mzlab/web/`): styles in `app.css` (in `index.html` only the theme background and the head scripts); classic scripts in `index.html` in the order written there, sharing the global scope (a duplicate `function` or `const` name breaks the page); globals `E` = files and panels, `S` = state, `NB` = notebook. The Data view is in five files (map at the top of this file): `explore.js` (loading, files, data, menus), `pannelli.js`, `grafici.js` (chromatograms, map), `picchi.js` (integration, spectra), `eventi.js` (mouse, keyboard, toolbar, calculator).
  `draw.js`, `mappa3d.js`, `workflow.js` and `perf.js` (`?perf`) are ES modules (`type="module"`: they start after all classic scripts; whatever the others need is on `window`, e.g. `window.WORKFLOW`); new files are born as modules (leaves that nobody calls by name are modules; `xlsx.js` stays classic because tests load it with `require` and `vm`); `xlsx.js` writes .xlsx without libraries.

The Space that starts playback cancels the "click" on release (`PLAY.space`).
  **Types without a build**: `tsconfig.json` composes three projects `tools/tipi/pagina.json`, `moduli.json` and `worker.json`. Details on `genera_globali.py`, `controlla_tsc.py` and `strictNullChecks` in `docs/agenti/test.md`.

## General pitfalls
- The service worker caches the app by version: a normal reload picks up the new deploy (`service-worker.md`). Link previews stay cached in messaging apps (`?v=2` on the link; with a new image the `?v=` of `og:image` in `build_site.py` also changes).
- A `title` on an iframe becomes a hint over the whole content: use `aria-label`. `ask()` returns `null` also for empty text: for "default value" use a word ("auto").
- **Row layout** (`layout.js`, `LAYOUT`): the panel stack is made of rows; a row has 1-3 panels (`riga`, `quota` in the notebook; without `riga` each panel is a row). `geometria()` is pure (minimums 440 px, 480 for maps; a row that does not fit is shown stacked without changing the saved layout), `colloca` gives the rectangles, `ordine` is the only reading comparator (y, x, id), `esci` removes a panel from its row, `altezza` gives the row a single height; `DDA.sync` uses the same geometry. Tests: `tests/test_layout_geometria.py`, `e2e_righe`.
- **Undo/Redo** (`storia.js`, `STORIA`): single stack of the Data view (100 entries / ~2 MB, no persistence). Details, keyboard shortcuts and handling of "Removed · Undo" in `docs/agenti/history-removed.md`. Tests: `tests/test_storia.py`, `e2e_annulla`.
- **Tiling panels** (`affianca.js`, `AFFIANCA`: handle, drop zones, menu, dividers, undo): `docs/agenti/panels-side-by-side.md`.
- **Legends** (`legende.js`, `LEGENDE.place`, called by `placeLeg`): the legend of chromatogram, XIC, MRM and spectrum (`leg2`: one row per file with the colour square, `specColor`) chooses among the four corners of the plot area (first top right) the one with the least ink of the canvas under it, peak labels included; if none is free, `p._legPad` adds margin above the data in the y axis (`picchi.js`, `grafici.js`) and the plot redraws once per view. Tests: `e2e_legende`, `e2e_legenda_spettro`.

- **Safe HTML**: `html-sicuro.js` gives the tagged template `h` (every `${}` goes through escaping, `raw()` lets trusted markup through); `tools/html_safe.py` (inside `controlla.py`) rejects new `innerHTML`/`outerHTML`/`insertAdjacentHTML` lines with `${` without `h` beyond the base `tools/html_sicuro_base.json`, which can only go down.

- **CSP and untrusted files**: the CSP in the meta of `index.html` has `object-src 'none'`, `base-uri 'none'`, `form-action 'self'` and `script-src` without `unsafe-inline`: inline scripts are allowed by SHA-256 (`python3 tools/csp_hash.py` rewrites hashes and the desktop CSP; `--check` and `tests/test_csp_hash.py` verify); `style-src` keeps `unsafe-inline` for `style` attributes. `tests_e2e/e2e_xss.py` loads a synthetic mzML with HTML in the file name, in the instrument and in the run id: nothing is created or executed and the console has no CSP violations.

## Key inventory, IndexedDB and cache
The central module `mzlab/web/nomi.js` (`NOMI`, classic script in `index.html` before `reset.js`) centralises the names of storage, databases and caches, handling the transparent migration from legacy `qqq` data to `mzlab`.
- **IndexedDB**: `NOMI.DB` = `"mzlab_lab"` (`NOMI.DB_OLD` = `"qqq_lab"`), version 2 (`DB_VERSION`), version 6 (`DB_VER`, schema in `qqq-db.js`). It holds the notebook (`notebook`), user lists (`user_lists`), OPFS manifest (`manifest`), `molecules` and key-value pairs (`kv`). At start-up the worker checks `mzlab_lab`: if empty and `qqq_lab` exists, it migrates store by store (`files`, `kv`, `user_lists`) with a cursor, compares the counts and sets `kv.migrated_from = "qqq_lab"`. At the 3rd confirmed start it removes `qqq_lab`.
- **Cache Storage** (`sw.js`): prefix `NOMI.CACHE_PREFIX` = `"mzlab-"`, app cache `NOMI.CACHE_APP` = `"mzlab-app-"` (with version suffix), vendor cache `NOMI.CACHE_BIG` = `"mzlab-big-"`. In the `activate` event it deletes the old caches with prefix `qqq-`.
- **LocalStorage and SessionStorage**: helper function `NOMI.KEY(k)`. It maps the exceptions (`"theme"` → `"mzlab-theme"`, `"labels"` → `"mzlab-labels"`), preserves strings with prefix `"mzlab"`, and for the others prepends `"mzlab."` (e.g. `NOMI.KEY("prefs")` → `"mzlab.prefs"`). At synchronous start-up `NOMI.migrateStorage()` copies the legacy `qqq.*` keys to `mzlab.*` with a read fallback (`NOMI.get(k)`). At the 3rd successful start (`mzlab.launches >= 3`) it removes the old keys.
  - *localStorage*: preferences and theme (`mzlab.prefs`, `mzlab-theme`, `mzlab-labels`, `mzlab.a11y`),
    admin and dev flags (`mzlab.admin`, `mzlab.dev.qaqc`, `mzlab.dev.riferimento`), Data views (`mzlab.peaks`, `mzlab.qaqc`,
    `mzlab.reference`, `mzlab.kmd`, `mzlab.map`, `mzlab.ordine`, `mzlab.pca`, `mzlab.pfas`,
    `mzlab.profile`, `mzlab.fair`, `mzlab.flgrp`, `mzlab.tunit`, `mzlab.lib.thresholds`), tour and updates (`mzlab.tour.lr`,
    `mzlab.upd.last`, `mzlab.upd.seen`, `mzlab.logo.gold`, `mzlab.reset.note`), TP_Mine (`mzlab.attributio.reviewer`,
    `mzlab.tabui.decisioni`, `mzlab.pipeline.draft`).
  - *sessionStorage*: phone flags (`mzlab.phone`, `mzlab.phone.scelto`), warning deduplication (`mzlab.unopen`, `mzlab.convopen`), tour (`mzlab.tour.step`).
- **Reset** (`reset.js`, `browser.js`): `wipe()` (and `qqHardReset()`, which calls it with `run("all")`) delete both the current `mzlab` data and the legacy `qqq` leftovers (databases `mzlab_lab` and `qqq_lab`, storage keys `mzlab.*` and `qqq.*`, caches `mzlab-*` and `qqq-*`).

# Built-in list of pesticides and environmental contaminants (`pesticides`)
Nearby areas: `data-tools.md` (list engine `liste.js`, Lists panel), `qc-mass.md` (mass check), `molecules.md` (catalogue and `structure:` classes).

- **What it is**: the second list of `mzlab/web/contaminanti.json` (`{"lists":[keller, pesticides]}`), 192 compounds: pesticides by chemical class (organophosphates, carbamates, triazines, neonicotinoids, strobilurins, azoles, phenylureas, pyrethroids, chloroacetanilides, sulfonylureas, phenoxyalkanoic acids...), metabolites and common environmental contaminants in LC-MS (PFAS, bisphenols, parabens, organophosphate esters, benzotriazoles, sweeteners).
- **Files**: `mzlab/chem/pesticides.csv` (`id;name_en;name;class;use;ions;query;pubchem_cid;formula;smiles;inchikey`, one row per compound; the Italian name is in `name`) and `mzlab/chem/pesticides_meta.json` (list header, source, IT/EN licence, closed vocabulary of `classes` and `uses` with Italian and English name).
- **PubChem columns**: `pubchem_cid`, `formula`, `smiles`, `inchikey` are written by `tools/download_pesticides.py` (by hand, with network) searching `query` or `name_en`; a name that yields more than one compound or a charged one stops the tool. Only descriptors computed by PubChem (NCBI places no restrictions).
- **Ions**: `contaminants.py` (`pesticides()`) expands each row into the adducts of the `ions` column (`[M+H]+`, `[M+Na]+`, `[M+NH4]+`, `[M-H]-`), m/z from the formula (`elements.py`, equal to `elements::ion_mz` within 1e-5, Rust test in `crates/mzlab-feat/tests/massacc.rs`). Each entry carries `tags` (`chemical:<class>`, `use:<use>`), `smiles`, `inchikey`, `source` = `PubChem CID n`.
- **Background**: the list has `"background": false`: `massacc::refs::background` and `tools/dati_sintetici_massa.py` skip it (a pesticide is not a background ion). Calculator ("Contaminants" group), palette (`ricerca.js`), formula window (`liste-nomi.js`) and peak annotation use it like any active list.
- **Generate**: `python3 tools/generate_contaminants.py` after every change to the two files; `tests/test_pesticidi.py` checks counts, unique `id`/InChIKey, formula = heavy atoms of the SMILES, m/z, classes and uses from the vocabulary, IT+EN names.

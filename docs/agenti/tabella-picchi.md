# Spectrum: peak table and % axis

- **Peak table** (`tabella-picchi.js`, `window.TABPICCHI`; "Peak table" button in every spectrum panel, hooked by `pannelli.js`, refreshed by `drawSpec`; test `e2e_tabella_picchi`): popover with the peaks the chart draws (`p._a.data[0].d`, intensity not in %), the rows of the spectrum data and the controls.
- **Controls**: "Min. threshold %" (2, steps of 0.5), "Max rows" (50, the most intense), order by increasing m/z or decreasing intensity, "Labelled peaks only" (`p._a.lbls`). In MS² two more columns: Δm/z from the precursor and neutral loss (precursor − m/z).
- **Output**: "Copy" writes to the clipboard a TSV with a header row and an html table; Ctrl/Cmd+C with the table selected gives the same TSV; "Copied" for 2 s. "Download CSV" (same text, `TABPICCHI.save`, also the "Peak list (CSV)" entry of the panel's download menu; name `plotName(p)_picchi.csv`) gives the same cells with comma, decimal point and UTF-8 BOM. With zoom the table keeps the peaks in the m/z window ("m/z range" row) and the base peak of the window is 100. Numbers use `I18N.num` (always the point).
- **Opening scale**: `specRel(p)` (spettro.js) returns `p.rel` when it is a boolean, else % for levels >= 2 (MS², MSn, every format) and absolute for MS¹. The "%" button and the "y axis" menu entry write `p.rel` (saved with the session only when boolean), so a user's choice survives zoom, redraws and a change of level. `drawSpec` syncs the "%" button with the scale in use; the data table (`tdati-pannelli.js`) gives absolute (`y0`) and %. Test `e2e_msn_relative`.
- **y axis in %**: exactly 0-100 (`ymax` 100, `ymin` 0, also `yfull`, zoom and reset; no lock): the base peak touches the top of the plot and its label overflows into the card margin above. `p._a.yticks` lists the axis values. Absolute mode keeps its 12 % headroom above the highest peak.
- **XIC button**: only on MS¹ spectra (`ms2` in `xic-spettro.js`); on MS² the peak choice and the `,` `.` keys are missing as well.

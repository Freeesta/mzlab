# Known contaminants panel: lists, Add list, provenance (`liste.js`, `reflist/1`)
Nearby areas: `data-tools.md` (panel, matching, exclusions), `pesticides.md` (pesticides list), `lists.md` (Flow lists), `cli-agenti.md`.

- **Add list** (`#lst-add`): «Add list…» (file picker), drop a CSV on the strip, «Download template» (`TEMPLATE` in `liste.js`). The CSV is read in Rust by `mzlab-core::reflist` (`reflist/1`): route `api/reflist` (`lr-map.js`), op `lr_reflist`, wasm export `reflist_parse`, desktop `rpc_lr.rs`, CLI `mzlab-cli db ref-list`. The page has no parser of its own.
- **Columns** (header required; `;`, tab or `,`; `#` lines and blank lines skipped; quotes allowed): `mz`, `name`, `formula`, `polarity` (`+`, `-`, `positive`, `negative`, `both`, empty), `adduct` (one of the seven adducts of `elements::adducts`), `note`. A row needs an m/z or a formula; with a formula only the ion is [M+H]+ ([M-H]- if the polarity is negative) unless `adduct` says another; with both, the m/z given wins. A polarity left empty is taken from the adduct.
- **Errors**: each wrong row gives `{line, key, field, value}` with the line of the file (`err.reflist.mz|formula|adduct|polarity|noMass|header|empty`), shown as «Line 3: …». Nothing is added until the person accepts «Add the N valid rows» (or cancels). `addUserListFromCsv(file, text, name, partial)` answers `{list, errors, valid}`.
- **Stored** in IndexedDB (`liste_utente`), on this computer only. Rename (inline), Remove and the on/off chip (hide) are in «About the lists»; the chip checkbox is the hide switch.
- **CLI**: `mzlab-cli db ref-list FILE.csv [--name N] [--match X [--set unit=da|ppm tol=N pol=+|-]] [--out PATH]`: the `reflist/1` JSON (same bytes as the page); `--match` adds the `reflist-match/1` answer against that list under `match` (see below). Exit 0 all rows read, 1 some rows wrong (good rows still in `items`), 2 usage, 4 unreadable file.
- **About the lists** (`#lst-about`): per list name (link to `info.url`), ions and compounds (`info.compounds`, `info.classes`), version and date, source line. `info` is written by `contaminants.py` into `contaminanti.json`: `url`, `doi`, `version`, `date`, `source_known`, `provenance`. Keller list: «Known contaminants (Keller et al.)», DOI 10.1016/j.aca.2008.04.043 (the DOI is in `chem/contaminants.json`, the date is the entry-by-entry comparison noted in its `_nota`). Pesticides: `source_known: false`, «Source unknown», version and date «not documented».
- **Tests**: `reflist/tests.rs`, `ref_list_tests.rs`, `parity_reflist.rs`, `e2e28.py`, `tests/test_contaminanti.py`.
- **Table lookup** (a number in `#lst-q`): `mzlab-core::reflist::lookup` (`reflist-match/1`): route `api/reflist_match`, op `lr_reflist_match`, wasm export `reflist_match`, desktop `lr_reflist_match`, CLI `db ref-list --match`. Request `{mz, pol, unit, tol, items:{mz,pol,group}}`; answer `{schema, unit, tol, hits:[{i, diff, err}]}` (`i` = position in `items`; ppm window floored at 0.001 Da under m/z 200; one hit per `group`; sorted by error). Hover tooltips, context menus and series detection keep the synchronous JS `find` (their callers are not async); only the panel table goes through Rust.

# Samples: file roles, times and metadata (`campioni/2` and `/3`)

One Rust model of the roles and times of the files of a series, for the Data view and for mzFinder: `crates/mzlab-core/src/samples/` (`mod.rs` types and `route`, `names.rs` name parser, `validate.rs` warnings and indices for the TP path, `json.rs` canonical JSON and migration). Schema: `docs/schemi/campioni-2.json`. Tests: `crates/mzlab-core/tests/samples.rs` (with `tests/samples3/` for the `/3`). The `/3` (below) extends the `/2`: same fields and same rules, plus the metadata of the physical sample.

## Model
- One `Campione` per file, in injection order. JSON fields in Italian, values in English: `file`, `sha256` (the key; empty if not yet known), `tipo` ∈ `sample t0 blank dark infusion std calibration qc pool` (`pool` only from `campioni/3`, in `per_tp` it goes with `qc`), `tipo_bianco` ∈ `solvent procedure wash` or null (optional: solvent and procedure are subtracted the same way; a `wash` is a rinse, in `per_tp` it goes with the standards: neither reference nor sample, no warning if missing), `tempo` + `unita_tempo` ∈ `s min h d` (as written or confirmed),
  `tempo_min` (derived, the only one used in calculations), `tempo_confermato`, `serie` (`""` = the only one, or shared by all), `replica`, `concentrazione`, `unita`, `ordine_iniezione`, `istd`, `note`, `composto` (for `infusion`, filled by mzFinder).
- `Campione::role()`: a `sample` at 0 minutes counts as `t0`. `set_time` derives `tempo_min` (`minutes_per`). The Data view never writes `tipo: t0` or `tipo_bianco` (a sample at 0 minutes and a single Blank type) and the time of the `dark` is negative; Rust still reads the old `t0` and `tipo_bianco` (`CDOC.fields` converts them).
- `to_json` is canonical (keys in alphabetical order, same bytes) and `digest` is its SHA-256; `from_json` rejects invalid schema, types, units and numbers (`error.badCampioni`) and recomputes `tempo_min`.

## `proponi(&[(nome, sha256, kind)])`
- One name parser, times always with `tempo_confermato = false`. Time = last number with a unit or prefix `t` (`Smp_01_30h_2` = 30 h; `Run_5` no time). Role and minutes follow `project::guess_sample` (same minutes on the generated names of `project_parity`, checked by the test), with in addition: seconds (`90 s`, `90s`), the replicate written `(2)` at the end of the name, infusion (`infusion`, `infusione`, `direct-infusion`, `FIA` or `kind == "msn"`), the dark (`dark`, `buio`, `adsorption`, `control`, `ctrl`), `tipo_bianco` from `solv…`/`proc…`.
- Blank words from the name (`wash`, `MQ`, `milliq`, `milli`, and `H2O` only as a whole token, never `H2O2`: table `crates/mzlab-core/data/nomi-bianco.json`, `blank_words.rs`) give `blank` only if every other token is a number or neutral (`pos`, `neg`, `q`, `init`); with `wash` the `tipo_bianco` is `wash`: with a time or series (`MQ_PMS_T00`) the file is a sample.
- With at least two different first words of 2-4 letters, each at the start of two or more names (`TW_`, `MQ_`), `proponi` writes the `matrice` on all files and the `gruppo` `MAT-COND` (series without matrix) on those with a time; a single first word proposes nothing; the user changes everything with the name template or by hand.
- `finder_base/sample.rs::guess` (mzFinder, golden `tests/golden/feat/finder.json["guess"]`) delegates to `samples::role_and_minutes` (same logic as `proponi`, without series or replicates) (blank→blank, dark→control, std/calibration→standard, other→sample; time only for samples). In `names.rs`: `control`/`ctrl` mean dark, "m" alone means minutes only after "t" (`t30m`; `S_30m` has no time), "(" closes the time (`x_t30min(2)`).
- The time is a whole token (start, end, space, `_`, `-` or parentheses around it; never inside a word: `H20`, `80-20`, `blk 90-10` have none): `t0` `t=0` `t 0` `t30` (minutes) or number + unit, with or without a space (`3h`, `3 hr`, `8hrs`, `30 min`, `T=3h`; units `s sec secs second(s)`, `min mins minute(s)`, `h hr hrs hour(s) ore`, `d day(s) gg giorno giorni`, `m` only after a `t`).
  Hours with minutes: `1 h 30`, `1h30`, `1h 30min` (two digits below 60, or with `min`; `3h_15` and `3h 2` are replicates). `d1` (day written first) only if the name has no other time. The last one wins; a bare number (`Run_5`, `80-20`) never; anything not in the list gives no time. Code `samples/time_token.rs`, table of cases `crates/mzlab-core/tests/samples_time.rs`.
- File list: a sample with no time text of its own (SIM, MRM, MS2) carries a mute tag with the time read from the name or written in the table ("t0", "3h", "90min"; `timeTag` and `timeBadge` of `ordine.js`, `title` and `aria-label` `files.time.title`), only if there is one; "Group by" offers the time (variable `time`, from the names).
- Without a unit in the name the time is proposed in minutes. A number before `ppm`, `mg/L`… is a concentration, not a time (`X25ppm_t10` = 10 min). Concentration only for standards and calibration. Infusion and QC have no time.
- The role words are searched in the name with the folders, like `campioni/1`; the time in the name without folders or extension.
- `serie`: the prefix before the time (`X_TiO2_t005min` → `X_TiO2`); if the files with a time have a single non-empty prefix, all are `""`. A file without a time takes the longest series its name starts with, otherwise `""`.
- Replicates numbered per series, role, minutes, concentration, polarity and matrix (`number_replicates`; for a `campioni/2` polarity and matrix are empty); the replicate written in the name wins.
- `tipo_v1(nome)`: the `campioni/1` type (without infusion), for `mzlab-feat/src/samples.rs`, which remains a wrapper with the same output.

## `valida(&[Campione]) -> Vec<Avviso>`
- `Avviso {code, severity, file, series}`; stable codes, the pages supply the words. JSON `{"avvisi":[{"codice","gravita","file","serie"}],"bloccante"}`; `bloccante` if there is an error (mzFinder does not start).
- Per file (errors): `timeMissing` (sample without a time), `timeUnconfirmed` (sample, even at 0 minutes, with an unconfirmed time), `t0WithTime` (`t0` with a time other than 0).
- Per series (the files of the series plus those with an empty `serie`): `noControls` (error: no t0, no blank, no dark), otherwise `noT0` and `noBlank` (warnings) and `noDark` (information); `onePoint` (warning: a single treated time); `replicates` (information: two treated with the same time and concentration).
- Overall: `noTreated` (error: no sample; with `noControls` if the controls are missing too), `noInfusion` (information).

## `per_tp(&[Campione]) -> PerTp`
- 0-based indices by role: `treated` (sample with time > 0), `t0`, `blank`, `dark`, `infusion`, `std` (with `calibration`), `qc`, `untimed` (sample without a usable time).
- `minuti[]` compatible with `feature_pipeline/1` (`genitore.minuti`): the time of the treated, 0 for the t0, null for all others; infusion is null and lives only in its index, never among the controls.

## `da_legacy(json)`
- Input `{"session":[NB.session v1], "qaqc":{"roles":{file: role}}, "campioni1":{campioni/1}, "mzflow":{"files":[...]}}`, each part optional.
- File order: session, then `.mzflow`, then `campioni/1`. Each field comes from the session, else from the `.mzflow`, else from `campioni/1`; the role of `qqq.qaqc` wins (it keeps QC and dark, which the session saves as `sample`). Session vocabularies: `standard` → `std`, `control` → `dark`.
- The times of the session and of the `.mzflow` are confirmed (written by the user), those of `campioni/1` are not. A `sample` at 0 minutes becomes `t0`; blanks, standards, QCs and infusions lose the time; the written replicate stays, the others are numbered.

## Binding
- One function per engine: `campioni(op, json)` in `mzlab-rotte-wasm/src/lib.rs` (Data view) and in `mzlab-feat-table-wasm` (mzFinder), with `op` ∈ `proponi` and `proponi3` (`{"files":[{"name","sha256","kind"}]}`, the second gives a `campioni/3` with matrix and group), `valida`, `per_tp`, `canonico` and `digest` (a `campioni/2`: canonical JSON and SHA-256), `da_legacy`. JSON errors `{error_key, params}` (`error.badCampioni`).
- mzFinder links only `route_finder`: `proponi`, `valida`, `per_tp`, `canonico`, `digest`, `da_legacy`; `proponi_spiegato`, `proponi3`, `ricollega`, `migra` are served by the site from `rotte` and by the app from `finder/campioni` with `route` (same bytes: `route_finder_same_bytes_as_route`; guard `test_finder_ops_are_in_route_finder`).
- `mzlab-core/src/project.rs` remains for parity with the Python of the main program.

## mzFinder Pipeline panel (`TP_Mine/files/finder-ruoli.js`, `TP_Mine/js/34_pipeline_run.js`)
- The functions of `finder-ruoli.js` that call Rust (`build`, `check`, `forTp`, `canonical`) are async: the `call` is the table's `.wasm` binding on the site and the native route `finder/campioni` (`pool.campioni`) in the app; `stemOf` also strips double extensions (`x.mzML.mzidx` of the app).
- The notebook keeps the roles in `NB.campioni` (canonical `campioni/2`, one entry per file, key = `.mzML` name). `build` starts from there; for files without an entry it migrates `NB.session` (v1) and the roles of `qqq.qaqc` with `da_legacy` (confirmed times) and proposes the others from the names with `proponi` (unconfirmed times).
- The panel shows a file/role/time table (native `select` and `input`, `aria-label`, focus restored after every edit) with a single unit selector; the proposed time is yellow until you confirm it (Enter or "Confirm times"). Short warnings in `role=status` come from the `valida` codes; "Run" is off, with the reason in the `title`, if `valida` is blocking.
- The pipeline receives `minuti[]` from `per_tp` and the canonical `campioni/2` (`campioni` of the parent → `build_evidence_to`, optional trailing parameter: TP gate 1 reads the roles, infusion is never a control); the run log also carries the `campioni` operation (canonical JSON and SHA-256 from Rust); Feature QC uses roles and minutes of the model.

## Tabui LR file table (`TP_Mine/lazy/gruppi-campioni.js`)
- After `TPLAZY.load("gruppi-campioni.js")`, `TPGRUPPI_FILES.mount(el, names, {R, call, nb, save, onChange})` draws File | Role | Condition | Time | Replicate (native `select`/`input`, `aria-label`, focus restored after every edit); `20_tpmine.js` mounts it in `#tp-cfiles` and gives the Dig the `campioni/2` (`docs/agenti/groups.md`, "Innesto in Tabui LR").
- The page that mounts the table waits for `window.nbEnsure()`, otherwise the notebook does not save. Roles, times, conditions (`serie`), replicates and warnings are those of `finder-ruoli.js` (`build`, `check`, `canonical`) on top of `api/campioni/<op>`: no name rule in JS.
- "Condition" has a `datalist` of the labels in use; "Set condition…" assigns it to the checked files; the proposed conditions and times are yellow until "Confirm conditions" is pressed (page state: entries already in `NB.campioni` at mount count as confirmed).
- The "Reference condition" `select` (with ≥ 2 conditions; default: the first called ref…/reference/control/no gas) is in `NB.gruppi_opts.reference`; the other fields of `NB.gruppi_opts` (`min_rep_frac`, `min_area`, `factors`) are kept as they are. `onChange` gives the page, at mount and on every edit, `{campioni, reference, conditions}` with the canonical `campioni/2` (`tempo_min` from Rust). A file without an entry in `NB.campioni` takes the proposals from the names (even if the v1 session of the Data view has an entry without a condition), except an already confirmed time.

## `ricollega(&[Campione], &[(percorso, sha256)]) -> Vec<Abbinamento>` (`samples/relink.rs`)
- Finds moved or renamed files: first by SHA-256 (among identical copies the same name wins), then by name without folders (`/` and `\`) only if at least one of the two SHA-256 is unknown, with `per_nome = true` (the page asks for confirmation). A known, different SHA-256 is a replaced file: never matched by name. A candidate serves only one file; a name shared by several free candidates is not guessed. Candidates are read in path order: same answer for any order. Test: `crates/mzlab-core/tests/relink.rs`.
- Binding `campioni(op="ricollega", {"campioni","file":[{"percorso","sha256"}]})` → `{"abbinati":[{"indice","per_nome","percorso"}]}` (nothing calls it yet).
## `order_like(text, names) -> Result<String>` (`samples/order.rs`)
- Puts the files of a samples document (`campioni/1`, `/2` or `/3`, other fields kept) in the order of a table's files, matched by name without folders: exactly first, then without the extensions of `EXT` (`T5` = `T5.mzML` = `T5.mzML.mzidx`). Same text when already in order, or when `names` is empty or has an empty name (a table that does not record its files).
- A table file with no sample, or a sample naming no file of the table, is `error.badCampioni` with `file`. The readers of the roles pair by position, so every step that holds a table calls it first with its meta `inputs` (`mzlab_feat::store::input_names`/`table_names`, `TpRoles::for_table`).
## Experimental design (`disegno/1`, `crates/mzlab-core/src/drawing/`)
- A plan datum (type `design` of `step/1`) with the conditions, the reference, the comparisons, the factors and the batches; schema `docs/schemi/disegno-1.json`, test `crates/mzlab-core/tests/drawing.rs`. It decides nothing: it proposes from the files and the user confirms; no statistical comparison.
- Canonical JSON (keys in alphabetical order, factors sorted by name, batches by `sha256` then `file`, levels by factor): same bytes for every permutation of the files, `digest` = SHA-256 for `prov/1`. Fields in Italian, values in English; `error.badDisegno`.
- `condizioni[]` = `nome` (a `serie`; `""` if it is the only one), `repliche` (the minimum number of `sample` files among the times of the condition, derived) and `livelli` (factor → value). `confronti[]` = `{tipo:"pair",a,b}` or `{tipo:"vs_reference"}` (every condition against `riferimento`). `fattori[]` = `{nome, valori[]}`. `lotti[]` = `{file, sha256, lotto}` (the key is the SHA-256 if known; default `"1"`).
- `proponi(&[Campione]) -> Disegno`: conditions from the `serie` of the `sample` files in injection order; reference = the first called `ref…`, `reference`, `control` or `no gas` (with "all against the reference" if the conditions are ≥ 2); a single batch.
- `valida(&Disegno, &[Campione]) -> Vec<Avviso>` (same `Avviso` as `campioni`): `fewReplicates` (warning, per condition with fewer than 3 replicates), `batchNoQc` (warning, per batch with samples without a QC before the first and one after the last), `emptyComparison` (error, condition without `sample` in a comparison), `refMissing` (error, "against the reference" without a reference).
- `route(op, json)`: `proponi` (a `campioni/2`), `valida` (`{"disegno","campioni"}`, answer like `campioni.valida`), `canonico`, `digest`.

## Positions in the name (`proponi_spiegato`, `samples/positions.rs`)
- `proponi_spiegato(files) -> Vec<Proposta {campione, positions}>`: the same values as `proponi` (which is a wrapper of it) and, for each proposed field, the part of the name that decided it, in characters of the whole name (folders included), end exclusive: `tipo` (the role word, or the time for a `t0`), `tipo_bianco`, `tempo` (number and written unit; without a unit only the number), `serie` (the prefix), `replica` (the written `(2)`), `concentrazione` (number and unit, or the number after the standard word).
- A field whose part is not found has no position (a bare `sample` has none); a name with capitals that change length: no position.
- Binding `campioni(op="proponi_spiegato", {"files":[...]})` → `{"campioni":<campioni/2>,"posizioni":[[{"campo","fine","inizio"}]]}`, one list per file in file order. Test: `crates/mzlab-core/tests/samples.rs` (values equal to `proponi` and positions inside the name on the over 30 000 generated names).

## Variables in the names (`samples/variables.rs`, `variable_classes.rs`)
- `campioni(op="variabili", {"files":[{"name"}], "manuale"?: {"pos":N,"sep"?} | {"has":[terms],"substring"?}})` → `nomivar/1` (keys in alphabetical order, fields in Italian, values in English): `comune` (equal part at head/tail, `MQ*T00`), `files[].tokens[]` `{classe,fine,inizio,testo}` (characters of the whole name; classes `folder matrix role time conc rep cond num word`), `variabili[]` `{copertura,id,punteggio,senza,tipo,valori[{chiave,etichetta,file}]}`, `manuale` (same shape, `multipli` for `has`).
- `id` ∈ `matrix cond time role matcond conc rep folder pos:N has`. `nome_gruppo` (`{"names":[..]}` → `{"nome"}`): the common tokens in the order of the first, with the most frequent separator (`""` if none). Limits 5 000 names and 256 characters: `error.badCampioni` with `limite`. Same bytes for every permutation of the names (except the order of `files[]` and the indices).
- Role, time and concentration belong to the name parser (`role_and_time`, `guess_conc`); the `t0` role counts as `sample`. A name without separators (`MQH2O2T00`) is cut into atoms (known word, chemical piece with element symbols, `T00`); `H2O2`, `TiO2`, `Na2SO4` stay whole.
- Matrix = first word of letters only (neither role nor condition) with 2-6 values on ≥ 2 files each; condition = the tokens between matrix and time (without a time no value: `BTZ`, `mid`, `Wash` are not conditions); replicate = number ≤ 20 at the end if the same name without it appears with another number.
- Score = coverage × balance (1 − normalized Σp², only + × /: same bits in `.wasm` and app). Hidden: constants, identifiers (categorical with one file per value, ≥ 3), score < 0.05. Order: above 0.25 the fixed `matrix cond time role matcond folder`, then by score (`conc`, `rep`).
- `has`: whole token (`O2` does not take `H2O2`) or `substring`; a file goes to the first term, those with several are in `multipli`, those with none in `senza`. CLI `mzlab-cli samples vars|group`.
- Tests: `crates/mzlab-core/tests/samples_variables.rs` (list of the study in `crates/mzlab-core/tests/samples_variables/federico.json`), `crates/mzlab-cli/src/samples_cmd_tests.rs`, parity `.wasm` = app in `parity_routes.rs` (`name_steps`).

## `campioni/3` (`docs/schemi/campioni-3.json`, `sample_id.rs`, `columns.rs`, `json3.rs`, `validate3.rs`, `csv.rs`, `model.rs`, `regex.rs`, `from_file.rs`)
- One file = one entry; a physical sample measured in the two polarities is TWO files with the same `campione_id`.
  Extra fields compared with the `/2` (all optional on reading, empty in a migrated `/2`): `campione_id`, `polarita` (+1, −1 or null: given by the file, a name template can propose it), `matrice`, `lotto` (the batch of `disegno/1`: `drawing::proponi` uses it, empty = default batch), `acquisito` (ISO `AAAA-MM-GGTHH:MM[:SS]`, local time of the instrument PC, from the file), `gruppo`, `extra{}` (name → text or number) and `dati_file` (only if read from the file: `modello`, `metodo`, `mz_min/max`, `rt_min/max`, `scansioni`; the user does not edit it).
- The document also has `colonne[{nome, tipo: testo|numero|categoria, valori?, obbligatoria?}]`, the declared free columns. The name maps of the CSV/English: condition = `serie`, replicate = `replica`, injection_order = `ordine_iniezione`, dose = `concentrazione` + `unita` (`25 ppm`), role = `tipo` (`control` = `dark`, `standard` = `std`), time = `tempo_min`.
- Canonical form (`to_json3`, `digest3` = SHA-256): keys in alphabetical order, files sorted by `ordine_iniezione` then by their own bytes, free columns and values by name, category `valori` sorted: same bytes for every permutation. `table_from_value` reads `/2` and `/3` (the `/2` is migrated: same `per_tp`); `from_json` also reads the `/3` (only the `/2` fields). Rust types: `Tabella {campioni, colonne}`, `Colonna`, `Cell` (`Testo`/`Numero`), `FileData`; the new fields of `Campione` are `sample_id`, `polarity`, `matrix`, `batch`, `acquired`, `group`, `extra`, `file_data`.
- `valida` (and `valida3`) adds to the `/2` codes: `missingValue` (error, `obbligatoria` column without a value; the warning carries `colonna`), `typeMismatch` (error: number in a text column, text in a number column, value outside a category's list), `duplicateKey` (error, from the second file with the same SHA-256, or the same name if missing), `pairMissing` (warning: a `campione_id` with a single polarity), `pairMismatch` (warning: positive and negative of the same `campione_id` with a different time, role or series). A column warning also has `"colonna"` in the JSON.
- `campione`: the sample inside a file that holds several (a `.wiff` with a series: index or internal name), empty if the file is one sample; the key of a row is file (or SHA-256) + `campione`, and `duplicateKey` uses it. `csv_leggi`/`csv_scrivi` also have the `campione` column (and `reiniezione`).
- `sample_id.rs`: the ID convention `MAT-COND-Ttt` (MAT `TW|MQ`; irradiated COND `C N2 O2 AIR H2O2 PMS`, dark `H2O2D PMSD BLKD` → `dark`; `tt` in minutes with `p` for the decimal, `T2p5` = 2.5; suffix `-R` = re-injection: `campione_id` keeps it, `reiniezione` = true, the pages exclude it from the kinetics), `MAT-STD<cc>` (`std`, concentration cc in mg/L), `QC-MAT` (`qc`), `P-<name>` (`pool`), `BLK`, `BLKP`, `SB`, `MQ_Wash`, `MAT-BLK` (`blank`).
- `modello` + `idcampione`: `modello` derives from it, for the fields the template did NOT capture, `matrice`=MAT, `serie`=COND, `gruppo`=`MAT-COND`, `tempo`, `tipo`, concentration; a captured field wins. The `{tempo}` placeholder also accepts the `p` (`2p5`).
- `valida`: `unknownCondition` (warning, column `serie`) for an ID `MAT-COND-Ttt` with an unknown COND; `typeMismatch` with column `tempo` (error) for an ID whose time part is not numeric.
- `modello` (`{"modello", "campioni"}` or `{"modello", "files"}` → `{"campioni":<campioni/3>,"posizioni","senza_corrispondenza"}`): a regex with named groups (`(?P<campione_id>[A-Z]\d+)_(?P<polarita>pos|neg)`) or a template with placeholders (`{campione_id}_{polarita}_{tempo}min_r{replica}`, without capitals). A group named like a field fills it (`campione_id`, `polarita`, `matrice`, `lotto`, `gruppo`, `serie`, `tempo`, `unita_tempo`, `replica`, `concentrazione`, `unita`, `tipo`, `ordine_iniezione`, `note`, `composto`); another name goes into a free column.
  The name is the one without folders or extension, whole (max 256 characters), positions are in characters of the whole name like `proponi_spiegato`; times stay unconfirmed; a file the template does not recognize stays as it was. Own engine in `regex.rs` (backtracking with a step cap; no dependencies): literals, `.`, classes, `\d \w \s`, groups, `|`, `* + ? {n,m}` (lazy with `?`), `^`, `$`, `(?i)`. Error `error.badModello`.
- `csv_leggi` (`{"testo","separatore"?: "," ";" "\t","colonne"?}` → `/3`) and `csv_scrivi` (`{"campioni","separatore"?}` → `{"testo"}`): headers = field names (also the English synonyms), unknown column = free column (number only if every value is written as Rust writes it, otherwise text; the types declared in `colonne` constrain), quotes `""`, line breaks and separators inside fields, BOM, empty rows skipped, separator detected by itself.
  `tempo_confermato` absent = confirmed if there is a time (the user wrote it); written replicates win, the others are numbered. What `csv_scrivi` writes, `csv_leggi` reads back identical (`tempo_min` is recomputed, `dati_file` is not in the CSV). Error `error.badCsv` with `riga` and `colonna`.
- `dal_file` (`{"campioni","file":[{"nome"?,"sha256"?,"polarita":[..],"rt_min","rt_max","mz_min","mz_max","scansioni","acquisito"?,"modello"?,"metodo"?,"metodo_json"?}]}` → `{"campioni","discordanze":[{"indice","campo","prima","dopo"}],"senza_campione"}`): the entry is matched by SHA-256 (if known), otherwise by name; polarity (a single one, otherwise null) and `acquisito` replace those proposed from the names (replacements of different values are in `discordanze`), the rest goes into `dati_file`.
  A `metodo_json` (`metodo/1`) gives `origine.file_creato`, `strumento.modello`, `campione.metodo_file` and the m/z range of the experiments when the entry does not say them. In Rust `riassunto_da_scansioni(&[Scan])` derives polarity, RT, scans and m/z (from the filter strings `[a-b]`) of an index.
- Binding: `campioni(op, json)` with in addition `modello`, `dal_file`, `csv_leggi`, `csv_scrivi`, `migra` (any `/2` or `/3` → `/3`); `canonico` and `digest` keep the schema of the input. The Flow metadata grid calls them (`flow-meta-grid.md`); polarity pairs: DEV-G.

# Signed offset and range in the "Extract ions" window; m/z edges of the XIC header
- A signed number at the end of an ion's text, `288.2+16` or `C9H10Cl2N2O-18`, is added to the m/z after the adduct as literal Da (+16 = 16.000, not oxygen). A text that ends with a sign or with letters (`+H`, `[M+H]+`) has no offset.
- The reader lives in Rust: `elements::split_offset`, used by `elements::formula_mz` (`api/formula`), which adds the key `offset`. A bare m/z with an offset answers without a formula (empty `formula`). Unreadable offset (`+1.2.3`, `+16x`, `288.2+`): `err.formula.offset`.
- Site and app give the same bytes: cases in `crates/mzlab-desktop/tests/parity_routes.rs` (`lr_formula`); reader tests in `crates/mzlab-core/tests/mz_offset.rs`.
- CLI: `mzlab-cli ion-mz TEXT [--adduct A] [--out PATH]` (`ion_mz_cmd.rs`) prints the JSON of `api/formula`; unreadable offset = exit 2.
- Interface: `evalRow` of `openXic` (`pannelli.js`) shows "base offset Da → candidate m/z", never an identification; the texts are `xic.shifted` and `err.formula.offset`. Test: `tests_e2e/e2e_xic_scarto.py`.
- Names: a text the engine does not read as a formula is tried as a name of the contaminant lists (`xic-nomi.js`, loaded on demand, with `liste-nomi.js` and `ask-suggerisci.js`): the engine error carries `head` and `offset`, the page looks up the exact name and calls `api/formula` again with formula + offset and the row's adduct. Suggestions under the field (combobox). A name is a candidate, never an identification; if the lists do not load, m/z and formulas work. Test: `e2e_xic_nomi.py`.
- Range: two numbers with the second larger (`250.8-251.5`) are not an offset (they would give a negative m/z) but an m/z range, low edge first: `api/formula` answers `{"formula":"","range":[lo,hi]}` and the row extracts exactly that window (label "m/z 250.8–251.5", note `xic.range`). An offset that leaves m/z < 1 (`251.5-250.8`, `C2H6-100`) is `err.formula.mzLow`. Cases in `mz_offset.rs` and `parity_routes.rs`.
- Default window in low resolution (file profile with `hr` false, `prof1` of `iteminfo.rs`): [n-0.2; n+0.3] with n the integer nearest to the clicked or typed m/z (`xicWin` of `pannelli.js`, `XIC_BELOW`/`XIC_ABOVE`; 264 → 263.8–264.3), title "m/z 263.8–264.3"; test `tests/test_xic_finestra.py`. It is not the spectrum cell [n-0.2; n+0.8) of `specpeaks.rs`/`peaks.py`, which covers the axis.
- "m/z from / to" fields of a low-resolution XIC: in the "Range" box (before the RT pairs, `aria-label` `ctl.xr.xlo`/`ctl.xr.xhi`), not in the title row (`xic-bordi.js`, `XICBORDI.wire`): ABSOLUTE edges, read when focus leaves the pair (Enter or click outside), so the window moves by writing first one or the other edge; the label becomes "m/z from–to".
- Rejected m/z edges: a rejected pair (not a positive number, from >= to): the previous edges return with the note `.xr-msg.xr-in` in the box (`xic.edge.num`, `xic.edge.order`). Esc as for the other pairs. Undo/redo (`xic.traces`) and saved session. Test: `tests_e2e/e2e_xic_campi.py` (also at 820 px).
- "From / to" pairs of the "Range" box (m/z or PDA nm, RT) in `xic-bordi.js` (`XICBORDI.range`, called by `ctl`, fields searched in the whole panel: at 320 px they sit in "More"): read when focus leaves the pair, empty = no limit, RT from 0, a single wavelength (from = to) allowed.
- "Range" pairs, rejection and keyboard: a rejected pair (letters, from above to): the previous values return with the note `.xr-msg.xr-in` inside the box (`ctl.range.num`, `ctl.range.order`). `keepFocus` gives focus back to the same field when the header is redrawn (Tab does not lose it); the box follows its button in Tab order, Esc closes it, discards a half-typed pair and gives focus back to the button. Undo/redo (`panel.source`) and saved session. Test: `tests_e2e/e2e_intervallo_campi.py`.
- Tab of a new panel from the "+" buttons (`tabNuovo`, `suTab` in `pannelli.js`; "+ XIC" also from the chromatogram menu, "+ chromatogram", "+ spectrum"): the active tab if it has at least one checked file, otherwise that of the first checked file (for XIC and spectrum never MRM), with `setTab` at creation (a cancelled window does not move the view); no checked file: the active tab.
- Panel without files to draw: the counter `n/N ▾` (`.fcount`, `ctl.files.title`) counts files shown / loaded of the panel's type; without checked files of the type the empty chart says `msg.noFiles` (`msgOf` in `grafici.js`). Test: `tests_e2e/e2e_xic_spuntati.py`.

# Figura e HTML del grafo MSn (`msngrafo/1` senza aprire l'app)

- **Codice** (`crates/mzlab-cli/src/`): `msn_figura.rs` (SVG statico: stesso layout `vista` albero/radiale della pagina, `completa` se manca, stessa regola dei testi di `msngrafo-vista.js`: m/z a 4 decimali, % relativa a 1, livelli, fino a 4 candidati (1 nel radiale), perdita come formula o «Δ x.xxx Da» con «(compatible with …)», regola «ids (weak), +n»; colori Okabe-Ito scritti nell'SVG, nessun CSS esterno), `msn_html.rs` + `msn_html.html` + `msn_html_pagina.js` (HTML autonomo), `msn_png.rs` (PNG), `msn_uscite.rs` (formati, scrittura, comando `figure`), `flow_msnfigura.rs` (passo).
- **Radice**: se il grafo ha un molfile con coordinate 2D la scatola della radice disegna la molecola (`molecola`, da `mzlab-mol`); con SMILES o molfile ma senza coordinate scrive «no 2D coordinates»; senza struttura niente.
- **HTML**: un solo file, nessuna risorsa esterna, nessuna richiesta di rete (CSP nel meta); contiene il JSON, il disegnatore `msngrafo-vista.js` (senza `export`), gli SVG di Rust delle due viste per i download, la tabella dei dati con «Copy data», vista Tree/Radial, zoom, tastiera (Tab sugli ioni, Invio per i candidati), axe 0 violazioni; 80 ioni ≈ 390 KB (limite 2 MB).
- **PNG**: feature cargo `png` (non predefinita, mai nel `.wasm`; `resvg`, MPL-2.0, ammessa da `deny.toml`) a scala 2 con i font di sistema, quindi il PNG dipende dai font installati; senza la feature l'errore è `err.msnfigura.png` con `build=cargo build -p mzlab-cli --features png`. Nel browser il PNG nasce dallo SVG con un canvas (`msngrafo-immagine.js`; anche l'HTML ha «Download PNG»).
- **Riga di comando**: `mzlab-cli msn-graph FILE --out STEM --figura svg,html[,png] [--vista albero|radiale]` (non con `--riassunto`, `--export`, `--strutture`) scrive `STEM.svg|html|png` accanto al JSON; `msn-graph figure IN.json [--figura …] [--vista …] [--out STEM]` parte da un grafo già fatto (predefinito svg,html).
- **Flow**: passo `msn.figure@1` (`graph` report → `figure` report; parametri `format` svg|html|png, `view` tree|radial, solo nativo), SEPARATO da `spectra.msn_graph` perché un'esecuzione dà un solo artefatto e ogni formato è una sua esecuzione; gli stessi byte del comando (prova in `msn_figura_tests.rs`); ogni parametro ha il suo `--set`; descrittore in `docs/schemi/steps-cli-1.json`.
- **Prove**: `msn_figura_tests.rs` (golden in `tests/msn_figura/`, riscritti con `MZLAB_UPDATE_FIGURA=1`), `tests/msn_figura_parita.js` (i testi di Rust = quelli del disegnatore, anche sul grafo da 80 ioni di `msngrafo_80.json`), `tests_e2e/e2e_msn_figura.py` (file://, rete, tastiera, download, axe).

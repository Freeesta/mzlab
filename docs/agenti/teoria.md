- **Indirizzi**: la Teoria è una pagina autonoma e leggera (`static/teoria/…`, file veri; nessun motore, nessuno script di Dati/Disegno); `teoria/` sulla radice del sito è un rimando di `build_site.py` (`teoria_entry`). `index.html#5`, `#cap-5`, `#A`, `#p2`, `#09-quadrupolo` portano al capitolo (`teoria.js`); `#/teoria`, `#/teoria/5` e `#/pratica` dell'app portano qui prima di caricare altro. Test `e2e_teoria_nav`; il titolo della scheda segue il capitolo.

Le figure statiche (`figure` con `svg`/`img`, non `.sim`, senza link) hanno `.fzoom` e si aprono in `#lb` (`role=dialog`): pulsanti ±/1×, tasti + − 0 e frecce, rotella, pizzico, doppio tocco, trascinamento; per le raster `data-full` è la versione grande, letta solo all'apertura (`esempio-*-m.png` è quella ridotta).

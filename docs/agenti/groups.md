# Experiment groups in Tabui: conditions compared (`groups/1`)

Pure Rust module `crates/mzlab-feat/src/groups/` (`mod.rs` types and `build`, `presence.rs` conditions and presence, `shapes.rs`, `sets.rs`, `prev.rs`, `json.rs`): compares the same degradation in several conditions on ONE alignment. It never reads files nor realigns: it uses the rows it receives. Schema `docs/schemi/groups-1.json`. Tabui is English only: no `lang/` key.

## Input and output
- `GroupTable {n_rows, n_files, area, height, state, apex_rt, rows: Vec<RowMeta>}` (cells `row * n_files + file`; `state` as `table::CELL_*`, a `TARGETED` counts as detected), `&[Campione]` in the same order as the columns, `GroupOpts`. `RowMeta {id, tp_name, mz, polarity, rt, neutral_formula, ppm, ion_formula, is_parent, ms2_files, other_polarity}`: the HR fields and `other_polarity` are filled by the caller (Dig LR, HR table); `ms2_files` = files with a matched MS2.
- `build(..) -> GroupsOut`, `groups_json(..) -> String` (English keys, fixed order, numbers as `Out::num`; ratios, `cv` and `rate_rel` to 6 decimals). `run_json(bytes)` reads `{"table":{matrices as lists of rows},"campioni":samples/1,"opts":{..}}`.
- Options: `reference` (null = no ratio), `min_rep_frac` 0.5 (0, 1], `min_area` 0 (off), `ctrl_ratio` 0.2, `shape_drop` 0.3 (0, 1], `norm` only `"raw"`, `factors` (condition → string keys/values, reported in `conditions[].factors`, never used). Errors `error.groups.noConditions`, `badOpts` (param = option name; `norm=istd`; `factors` not a string or with a non-existent condition), `sizeMismatch` (param `what`).

## Rules
- Conditions = distinct non-empty values of `series` of the samples with `role() == "sample"`, in the order of the smallest `injection_order` (not of the column index: so the output does not depend on the file order). Every file list is sorted by (order, name): sums and bytes identical for any permutation of the columns (indices aside).
- Controls (t0, blank, std, dark) per type: the condition's files if there are any, otherwise those with `series == ""`. Replicates = files with the same (condition, `time_min`); an unknown time forms a group of its own (counts for presence, not for `kin`).
- `dark` per cell (optional, `dark_course` in `mod.rs`): mean area of the condition's dark controls at each known time (same fields as `kin`); absent if the darks have no time. Test `crates/mzlab-feat/tests/groups_dark.rs`.
- Area of a group = mean of the detected replicates (sample sd, `cv = sd/area`); if none is detected, mean of the filled ones (shows how absent "absent" is); otherwise 0. `area`, `n_det`, `n_rep` are those of the last time.
- `present` = detected in at least `ceil(min_rep_frac · n)` replicates of a treated time, with mean area ≥ `min_area`; filled cells do not count. `only_in` and `in_all` only with ≥ 2 conditions. `sets`: exact combinations (never empty), by decreasing number of rows then by names.
- `ratio_ref` = area(cond)/area(ref) at the highest time they have in common; 1 for the reference, 0 if the condition is not present, null if the reference is absent, there is no reference or no common time.
- `shape` (only where present): `single` (one time); with two times `rising` (second > 1.5 × first), `decay` (first > 1.5 × second) or `flat`, never `bell`; with three or more `flat` (max/min < 1.5), `rising` (maximum at the last time, or drop after the maximum < `shape_drop`), `bell` (drop ≥ `shape_drop`), `decay` (maximum at the first). `t_half_rise` (interpolated) only for `rising` and `bell`; `rate_rel = t_half_rise(ref)/t_half_rise(cond)`.
- `prev` (null if not present or if the row is `is_parent`): `absent_t0`/`absent_blank` pass if the maximum area detected in the control ≤ `ctrl_ratio` · maximum treated area; `in_parent_std` yes if it exceeds it (only a hint, never an exclusion); `above_min` na if `min_area` = 0; `ms2` na if no row has MS2. Verdict: "Prev. unlikely" if t0 or blank have the ion; "Prev. possible" if the parent's standard has it or t0/blank is missing or the MS2 is not matched; otherwise "Prev. likely". No Schymanski level, no row removed.
- `parent` per condition: the row with `is_parent`, `legacy::lr::kin::decay` on the detected times (k, t½ with ≥ 3 points) and `remaining` = area at the last time / mean area of the condition's t0.
- Warnings (sorted by code, then condition): `refMissing`, `condNoControls` (neither t0 nor blank), `condOnePoint`, `condNoReplicates` (no time with ≥ 2 replicates), `mixedTimes` (times different from those of the reference, or of the first condition).

## High resolution
- The HR products table gives `groups/1` from `tp/groups.rs` (`groups_json`): requested rows of `tptab/1`, areas from the `Aligned`, `neutral_formula`, `ion_formula` and `ppm` from `RowInfo` (best hypothesis given by the caller), `tp_name` "TP <id>" or "Parent"; only with ≥ 2 conditions. `condition_files` exposes to `tp/` the files and controls of each condition. Details in `docs/agenti/mzfeat-tp.md`.

## Proof
- `crates/mzlab-feat/tests/groups.rs`: fixture `tests/data/groups_fixture.json` (input + `expected`, byte for byte; rewritten with `GROUPS_FIXTURE_WRITE=1`), presence with replicates, sets, ratios, shared and per-condition controls, errors, determinism over 5 permutations, performance (`#[ignore]`: `cargo test --release --test groups -- --ignored --nocapture gruppi_speed`, 2 000 rows × 60 files ≈ 40 ms native, cap 50 ms). `tests/groups_shapes.rs`: shapes, `t_half_rise`, `rate_rel`, parent decay. Synthetic data only (`tests/groups_common/mod.rs`).

## In the low-resolution Dig (`crates/mzlab-feat/src/legacy/lr/`)
- **Input**: the file list of `finder_lr_plan`/`finder_lr_dig` is a list or `{"files": [...], "samples": samples/1}`; each file can carry `cond` and `replica`, and with `campioni` role (`role()`), time (`time_min`), condition (`series`), replicate and injection order come from there. `FileLr`/`FileIn` have `cond`, `replica`, `order`. The `groups` options are in the `groups` key of the settings (`Settings.groups`, module default).
- **Per condition** (`cond.rs`, only with ≥ 2 conditions; with one the output is byte for byte that of a single kinetics): each row is judged in every condition on that condition's columns (`members`: its treated ones; for t0, for the blank and for the dark control, each kind apart, its own files if there are any, otherwise the shared ones with empty `cond`) and carries the criteria of the condition where the score is highest (`Entry.cond`; tie = the first).
- **Kinetics**: "grows over time" asks for at least 3 different times in the condition: with one time per condition it stays "n/a". The kinetic generation uses the best condition (`GensBy`); the parent's `decay` is that of the reference condition (or the first).
- **Parent standard**: with ≥ 2 conditions the standard is a column of the table (needed by `in_parent_std`); with one it is not.
- **Output**: `"groups": <groups/1>` in `summary` only with ≥ 2 conditions (`groups_out::block`): rows = the rows shown by the Dig, cells from the alignment table (detected, filled or absent: the filling is that of the pipeline, no new peak search),
- **Dig rows**: with ≥ 2 conditions each Dig row also names its best condition (`cond`) and repeats its evidence per condition (`by_cond`: `k_points`, `blank`, `dark`); each point names its `cond` (`mzfinder-lr.md`). The Flow `tp.dig_lr` with two `series` in one plan gives the page's bytes (`flow_lr_tests.rs`).
- **Rows**: `tp_name` from `nomi::tp_names`, `ms2_files` = columns of the same condition and time as a matched MS2 file (`ms2link`); an MS2 file without condition is shared: it applies to all the samples' columns (at its time, if it has one), formulas `null`.
- **Order and polarity**: conditions come out in the order of the injection order of `samples/1` (without it, of the file names, never of the position in the list). `mz` is rounded to 4 decimals. The LR Dig has a single polarity (all rows "+"): `other_polarity` (`groups_out::other_polarity`: same neutral mass within `tol_da`, RT within `rt_tol_min`, opposite polarity) is for those who mix polarities.
- **Proof**: `crates/mzlab-finder-lr-wasm/tests/lr_groups.rs` on the 38 mzML of `tests/data/groups/` (truth in `attesi.json`): presence, `sets`, shapes, ratios ±10 %, no "grows over time" with one time per condition, one row per product with RT drift, 5 permutations of the files, one condition = unchanged output. Measurement in `measurements.md`.

## Choices and success criteria
- **Choices**: a condition is the `series` of `samples/1` (free label; empty `series` = shared controls, one with its own `series` applies only there and wins); a single alignment of all files, never a Dig per condition; separate rows for + and − ("also in ESI−/ESI+" only as a hint); raw area; the standard of the parent alone is a "Prev." hint, never an exclusion; the second factor (`factors`) without a view.
- **Criteria 1-4** (`crates/mzlab-finder-lr-wasm/tests/lr_groups.rs`): (1) with a single condition the output of the LR Dig and of the HR `tp_table` stays byte for byte equal; (2) on the synthetic truth presence, `sets`, `only_in`, `in_all` equal, right `shape` for the designed TPs, `ratio_ref` within ±10 %, no growth over time with a single time; (3) with ±0.1 min drift a TP has a single name in all conditions; (4) same `groups/1` bytes for every file order.

## "Compare conditions" view (`TP_Mine/lazy/groups-view.js`)
JS formats and draws; every computation (presence, means, ratios, sets, shapes, "Prev.") belongs to Rust.
- `window.TPGROUPS_VIEW.mount(el, gruppi, { parentName, onOpenRow(rowId) })` draws a `groups/1` and returns `{ destroy, setFilter, selectRow, state, csv }`; `// @ts-check` file in `tools/tipi/pagina.json`, loaded on first opening (never in `TP_Mine/js/`). The hook into the TP table is not this file's.
- **Matrix**: one row per TP (name, m/z, RT, "Neutral formula", "[M+H]+ formula" (`ion_formula`, empty if null) and "Δ ppm" only if present), one column per condition (reference first, marked "ref"); cell = ● / ○ with text for screen readers, area in scientific notation, ratio (`×2.3`, `only here`, `—`), "Prev." token with the evidence in the `title`. Sorting with the header buttons; arrows, Home, End and Enter on the TP names; Enter opens the row (`onOpenRow`) and chooses the chart's TP.
- **Filter** (`select`): "All rows", "In all conditions", "Only in …", "Present in …", all from the `sets`; a click on an UpSet bar filters by that set (second click = removes).
- **UpSet** (SVG): vertical bars of the `sets` (the 20 largest), condition dots below, horizontal bars of the totals; each column is a 30 px target (arrows, Enter/Space); zoom with "−"/"+", no dragging.
- **Chart of the chosen TP**: a single time per condition = grouped bars (segment = standard deviation); more times = one curve per condition on the same axis, a different marker per condition. Choices: "Overlaid" / "Side by side" (same y axis; alone above 8 conditions), "Area" / "% of max" / "% of each own max" (parent dashed by `k` in the two percentages), "Compare" (conditions with the same name ending or beginning, e.g. TW_PMS and MQ_PMS: only a choice of curves).
- The condition's dark (`dark` of the cell, optional: only if the darks have a time) is a dashed curve with hollow markers. Okabe-Ito from `--gv1..8` (above 8 no legend).
- **Kinetics** (`TPGROUPS_VIEW.kinetics(el, gruppi, opts)`): only the TP chart (selector, choices, data table) and the parent table; it is the kinetic detail of Flow (`flow/lazy/flow-views-tptab.js`, with `j.groups`). `tests_e2e/e2e_tabui_cinetiche_condizioni.py` proves it (layout, modes, comparison, dark, table, axe, 360 px).
- **Data tables**: UpSet and chart have a description and a "Dati" button (`TDATI`, key T); the small multiples have a single "Data" button. Parent table per condition (k, t½, remaining fraction); `warnings` notices on top (`role=status`).
- **Exports** (English buttons, rows shown by the filter): `tabui_conditions_<parent>_<yyyymmdd>.csv` (long: TP × condition × time), `tabui_conditions-wide_<parent>_<yyyymmdd>.csv`, `tabui_sets_<parent>_<yyyymmdd>.csv`, `tabui_gruppi_<parent>_<yyyymmdd>.json`; charts `tabui_upset_<parent>.svg|png`, `tabui_tp-<mz>_conditions.svg|png` (standalone SVG with resolved colors, PNG at 2×); `<parent>` in lowercase with spaces as `-`. Download with `dl()` without provenance.

# Molecules database (`molecules/1`, `crates/mzlab-core/src/molecules/`)
Related areas: `samples.md` (the structure model), `liste.md` (CSV and canonical JSON), `rust-rotte.md` (the routes), `mzfinder.md` (Tabui's "Name" field). Schema `docs/schemi/molecules-1.json`.

- **What it is**: one record = one molecule (`id`, `nome`, `sinonimi`, `formula`, `carica`, `massa`, `smiles`, `inchikey`, `addotti`, `raccolte`, `classi`, `esterni` (`cas`, `pubchem_cid`), `proprieta`, `note`, `origine`). Fields in Italian, values in English. The engine gives no verdicts: it holds and searches data.
- **`id`**: `ik:<full InChIKey>` if there is an InChIKey, otherwise `u:<12 hex of the SHA-256 of the record's canonical JSON at birth>`; assigned by `finalizza` when empty and never changed again (renaming a molecule does not change the `id`).
- **Mass**: COMPUTED from `formula` (Hill order, `elements::fmt`) and `carica` (`pysum` of the masses minus `carica` electrons), to 6 decimals; in files it is a check column: if it differs by more than 0.0005 Da the row has `error.molecules.massMismatch`. A `massa` in the JSON is ignored.
  - **Mass-only entry**: without `formula` and with a positive mass (column `mass` or `massa` in the JSON) the entry stays with an empty `formula` and that mass, as is to 6 decimals (`carica` ignored); without a mass it is `badFormula`. It is found by name and by mass and enters the HRMS lists; it has no formula to write in the ion field.
- **CSV** (`csv.rs`): separator `;` (or tab or comma if the header has no `;`), empty lines and `#` skipped, double quotes also across lines, BOM removed. Canonical columns in the order of `COLUMNS`: `id;name;synonyms;molecular_formula;charge;monoisotopic_mass;smiles;inchikey;adducts;collections;classes;cas;pubchem_cid;notes;origin;catalog`, then for each property `prop:<key>[<unit>]` + `prop:<key>:source` (mandatory) + `prop:<key>:conditions` (only if someone uses it; with two units for the same key the source is `prop:<key>[<unit>]:source`).
- **Cells and columns**: lists in a cell are separated by `|` (an element containing `|` is `error.molecules.badList`). On reading, the header gives the columns in any order; `name` and `molecular_formula` are mandatory.
- **Errors**: every wrong row gives a `RowError` (row, key, text) and the file is rejected if there is one: `noName`, `badFormula`, `massMismatch`, `badMass`, `badInchikey`, `badCharge` (not an integer), `badProperty` (without unit or source, or a non-numeric value), `dupProperty` (two values for the same key), `badList`, `badOrigin`, `badId`, `dupId` (at the second row with the same `id`), `badColumn`, `noColumn`.
- **Row in the JSON**: the "row" of an error is the position of the record (from 1).
- **Canonical JSON** (`json.rs`): `{"molecole":[...],"schema":"molecules/1"}`, keys in alphabetical order, records sorted by `id`, `sinonimi`/`raccolte`/`classi` sorted without duplicates (case ignored; synonyms without the `nome`), `addotti` in the given order, `proprieta` by key.
- **Digest**: `digest()` is the SHA-256 of the canonical bytes (it enters `prov/1` when a step uses the molecules). CSV → JSON → CSV gives the same bytes if the CSV is canonical and sorted by `id`.
- **Order**: the CSV keeps the row order (the catalogue is in its own order); the JSON is always sorted by `id`.
- **Levels** (`levels.rs`): catalogue < imported < user. `unisci(catalogo, altri)`: the same `id` higher up replaces the whole record, in place of the first; new ones follow. "Edit" of a catalogue molecule = the user's copy with the same `id`; removing it brings the catalogue one back.
- **Search** (`search.rs`, a single one): `cerca(ms, q, limite, ppm)`. A number is a mass (`|q − massa| ≤ massa·ppm·1e-6`, ordered by deviation, the `punteggio` is the deviation in ppm); a valid formula (one C or at least two elements) is the same Hill formula (`punteggio` 0) and then also text; text (≥ 2 characters, lowercase) on `nome` and `sinonimi` gives 0 equal, 1 starts with, 2 word start (after space, `-`, `(`, `,`), 3 contains, looking only at the first occurrence like Tabui's old field; at equal score the shorter `nome` wins, then the order.
- **Numbers**: a number is NEVER searched as text (a whole CAS with hyphens is).
- **Routes** (`routes.rs`, `route(op, input)`, JSON in and out): `carica` (`{"catalogo": CSV text, "utente": document}`, each optional: what is missing stays; keeps the catalogue and the user's molecules in the engine, in a `static Mutex`),
  `cerca` (`{"q","limite"=8,"ppm"=10}` → `[{id,nome,formula,carica,massa,smiles,addotti,punteggio}]`), `get` (`{"id"}` → record or `null`),
  `elenca` (`{"catalogo"|"raccolta"|"molecole": document, "addotti":[..]}` → `[{id,nome,sinonimi,formula,massa,mz:[one per adduct, null if unknown]}]`: the molecules of a catalogue or a collection, or of a document not in storage, with the m/z computed by the engine).
  `cerca` with `"ampia":true` (`search_wide`: the same answers, then the molecules of a full InChIKey or of the first block of 14 characters, and only if there is nothing the names one letter away, score 4 whole name and 5 start of name, from 4 characters),
  `addotti` (the names of the `elements::adducts()` table), `ione` (`{"q","adduct"}` with `adduct` = `neutral` or an adduct: a formula is the ion and the adduct's atoms are removed (`composition::adduct_atoms`), an m/z loses the table's offset → `{kind, adduct, formula, massa, mz}`; adduct absent from the formula = `err.ion.notHeld`),
  `da_csv` (`{"csv","file","livello"=importata,"raccolta"}`: with `raccolta` every record enters that collection; the header also accepts `formula`, `mass`, `comment` for `molecular_formula`, `monoisotopic_mass`, `notes`; the page passes the file name without extension → document, or `{"errori":[{riga,chiave,testo}]}`),
  `valida` (`{"csv"}` → `{"errori","n"}`), and on a document `a_csv` (CSV text), `a_json` (canonical, `id` assigned), `digest`.
- **Where they arrive**: page `api/molecules/<op>` (`lr-map.js` → `lr_molecules` in `rust-worker.js` → `molecules` of `crates/mzlab-rotte-wasm/src/lib.rs`, module `rotte` loaded at the first request); the desktop app answers the same ones (`rpc_lr.rs`).
- **Catalogue**: `mzlab/web/molecole/catalogo.csv` (1228 records, canonical form), a static file that the page passes to `carica` once; it is NOT in the `.wasm`. Rows in the order of `composti.csv` (`catalog = tabui`), then only the `hrms` ones; the 43 common ones (same full InChIKey) are one `tabui|hrms` record with the name from `composti.csv` and the other names as synonyms. The adducts' m/z are not copied: the `hrms` rows have `adducts = [M+H]+|[M+Na]+|[M+NH4]+`.
  `tools/generate_molecules.py` wrote it from the two earlier CSVs plus the `ADDED` list (records added later, at the end: timolol, `tabui|hrms`).
- **`structure:` classes**: read from the SMILES with fixed rules (`tools/classes_structure.py`, called by `generate_molecules.py`): `carboxylic_acid`, `ester`, `sulfonamide` (only C-SO2-N), `nitro` (on C or N, not nitrates), `quaternary_ammonium`, `fluorinated`/`chlorinated`/`brominated`/`iodinated`; no use or effect inferred. Closed vocabulary of types: `chemical`, `effect`, `psychoactive`, `role`, `structure` (`tests/test_classi_struttura.py`).
- **Tests**: `crates/mzlab-core/tests/molecules.rs` (CSV/JSON round trips, one error per row, search, levels, catalogue rewritten to the same bytes, parity with Tabui's "Name" field with `tests/data/molecole_tabui_oro.json` made by `tools/molecole_oro_tabui.mjs`: the order of the Tabui-only molecules is identical and none of the 43 common ones is lost, but these may also appear under the `hrms` names),
  `hrms_list_keeps_the_mz_of_the_old_csv` (the m/z of `elenca` on the `hrms` catalogue equal within 1e-5 to `tests/dati/molecole_hrms_oro.json`), `tests/test_molecole_migrazione.py` (no loss with respect to the two earlier CSVs), `tests_e2e/e2e_molecules.py` (the routes in the page, `MZLAB_LR_MISS` empty).
- **User storage** (routes `api/molecules/archivio/leggi` and `archivio/scrivi`, op `lr_molecole_archivio`): browser = IndexedDB `mzlab_lab`, store `molecole` (keyPath `id`, one `molecules/1` record per row, `DB_VER` 4 in `qqq-db.js` and `nomi.js`; `upgrade()` only adds the store, the other four stay), read and written by `rust-worker.js`; desktop app = `molecole.json` in the data folder (`store.rs`, `Store::molecules`: canonical JSON of the same `a_json`, written halfway and renamed; an invalid document is rejected and the file does not change).
  Neither "New session" nor `lr_clear` touches it; `scrivi` replaces all records with those of the document.
- **Page** (`molecole-archivio.js`): `pronto()` loads `static/molecole/catalogo.csv` and the storage once with `carica`; `cerca`, `prendi` (`get`), `salva` (validates with `a_json`, the engine gives the `id`; a new molecule with an `id` already present is `esiste`), `elimina`, `esporta`.
  `importa` (CSV with `da_csv`, JSON with `a_json`, level `importata`; a molecule with the same `id` as one of the user's (level `utente`) stays as it is and is counted in `tenute`); `esporta` gives CSV (`a_csv`) or canonical JSON of the whole storage. No computation in JS: Hill formula, mass, `id`, per-row errors and CSV/JSON belong to the engine.
- **"Molecules" window** (`molecole-ui.js` + `molecole-modulo.js`, ES module `@ts-check` loaded at the first click on the "Manage" link of the molecule field; `window.MOLDB.apri()`): without a search it lists the user's molecules, with at least 2 characters the results of `cerca` (50); columns name, molecular formula, mass, origin (Catalogue, Imported, Yours); "Edit" opens the form (a catalogue molecule is saved as a `utente` copy with the same `id`), "Delete" (only `utente` and `importata`, with a question; focus goes to "Cancel") brings back the catalogue one if there was one.
  Import: `.csv`/`.json` file, a file with wrong rows imports nothing and shows one line per error (`error.molecules.*` translated, `{riga}`); Export CSV and JSON downloads `mzlab-molecules.csv`/`.json`.
  Tab stays inside, Esc goes back from the form or closes, focus returns to the button.
- **Search field** (`molecole-campo.js`, `MOLDB.campo(host, {testi, onScegli, limite, ppm, gestisci, valore})`): ARIA combobox (`role=combobox`, `aria-expanded`, `aria-controls`, `aria-activedescendant`, listbox with `role=option`, announcement of the number of results in a `status` region), arrows, Enter, Esc, 120 ms wait, at least 2 characters. All texts are passed by the caller (`testi.label/placeholder/none/count/manage`: Tabui passes English); with `testi.manage` there is the "Manage" link that opens the window (or `gestisci()`).
- **Tests**: `tests_e2e/e2e_molecole_ui.py` (only invented molecules "Esempina", "Provolone B": keyboard, add/edit/delete, catalogue copy, import with errors, export and reimport, reload, migration 3→4 with rows in files/kv/liste_utente/manifest, combobox, axe light and dark), `tests/test_molecole_db4.py`, `store::tests` and `tests/rpc.rs` of the desktop.

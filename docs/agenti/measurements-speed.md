# Cumulative table of speed measurements

One row per speed change (readers, Flow, engine), oldest first; the row is added in the same PR that makes the change. Rule of 22/10: even gains of a few percent count (a new dependency from ≥ 3 % on its target). A gain counts only if it exceeds the measured noise (`noise` of the bench, `thermo-speed.md`); before and after with the same bench binary, the same machine, the fastest run (`best`) over ≥ 15 runs and the 40-character SHA of `main` for the "before" measurement.

Abandoned or postponed routes (without gain) are in `optimizations-tried.md`: read it (and `measurements-one-pass.md`) before optimizing.

Site loading (page, first paint, batches of files, first file of a batch) has its own table: `measurements-speed-site.md`; the page measurements (FCP, LCP, engine ready per scenario) are in `measurements-loading.md`.

# «Group by» della lista file laterale
File d'area di `gruppi.js` e `gruppi-per.js` (il menu `#sb-by`); i gruppi dell'utente (`ugrp`, intestazioni) stanno in `docs/agenti/dati.md`.
  **«Group by»** (`#sb-by` in `#sb-header`, larghezza fissa; `gruppi.js` e `gruppi-per.js` si caricano con `carica()` al primo uso): `GRUPPI.by(chiave)` scrive `ugrp` di ogni file con l'etichetta del suo valore (risposta `variabili` di `api/campioni`, la pagina non taglia mai un nome; «—» = nessun gruppo) in UN passo `files.view` (chiave `E.ugBy` e ordine `E.ugOrder` nell'istantanea e nel blocco `ui`), sostituisce i gruppi a mano con «Groups replaced · Undo» in `#fl-note`; «None» li toglie.
  Menu `role=menu` di `menuitemradio` (variabili con anteprima «MQ 20 · TW 9», «Then by…», «Token position…» e «Contains…» in `<dialog>` con anteprima, «Custom»). I file che arrivano dopo seguono la chiave (`GRUPPI.follow`, 300 ms) finché non è `custom`; una modifica a mano (`ugSet`, `GRUPPI.set`) la imposta. `GRUPPI.order` ordina i gruppi dell'utente in `renderFileList`.

# "Group by" of the side file list
Area file for `gruppi.js` and `gruppi-per.js` (the `#sb-by` menu); the user's groups (`ugrp`, headers) are in `docs/agenti/data.md`.
  **"Group by"** (`#sb-by` in `#sb-header`, fixed width; `gruppi.js` and `gruppi-per.js` load with `carica()` on first use): `GRUPPI.by(chiave)` writes the `ugrp` of each file with the label of its value (`variabili` answer of `api/campioni`, the page never truncates a name; "—" = no group) in ONE `files.view` step (key `E.ugBy` and order `E.ugOrder` in the snapshot and in the `ui` block), replaces manual groups with "Groups replaced · Undo" in `#fl-note`; "None" removes them.
  **Flat list and button**: if all the user's groups have a single file, `renderFileList` writes no headers (flat rows, the labels stay on the files); `syncGroupBy` (`lista-file.js`) hides `#sb-by` when there are fewer than 2 files or when neither the list nor `GRUPPI.useful()` (a variable with a value on 2+ files) gives a group of 2+ files; the chosen key stays and applies again. Proof: `e2e_gruppi_singoli`.
  Menu `role=menu` of `menuitemradio` (variables with a preview "MQ 20 · TW 9", "Then by…", "Token position…" and "Contains…" in a `<dialog>` with preview, "Custom"). Files that arrive later follow the key (`GRUPPI.follow`, 300 ms) until it is `custom`; a manual change (`ugSet`, `GRUPPI.set`) sets it. `GRUPPI.order` orders the user's groups in `renderFileList`.
  **Dragging between groups** (`gruppi-dnd.js`, lazy; `GDND.bind(lista, {rowSel, headSel, keyOf, onDrop})`; the side list uses it with `GDND.start(k)` from `bindDragDrop`/`bindFileReorder`): a row dropped on a group header adds it, with the checked files if the dragged row is checked.
  On an automatic header of its own type or in the free space below the last group (not with a finger) it removes the label; a header of another experiment type accepts nothing. A single `GRUPPI.set` step (`E.ugBy = custom`); reordering between rows stays with `bindFileReorder`.
  **Drop ONTO a file** (side list and table): the middle third of a row is "onto" (`.gdnd-onto`, announcement "New group with …"; a finger, or a row lower than 40 px, needs a 600 ms dwell, `DWELL`), the two outer thirds reorder as usual. `GRUPPI.onto(basi, bersaglio)`: if the target has a group the files join it ("join" step), otherwise a group is born ("new" step) named after `nome_gruppo` or "Group N" if empty or already used (`GRUPPI.newName`) and its name opens in `GRUPPI.rename` (Esc keeps it).
  The host's listeners are in capture and stop propagation only on "onto" (the row handlers of `explore.js` do not reorder). From the keyboard: "Group with…" in the row menu (`groupWith`, `<datalist>` on the `ask` prompt).
  Every group action is ONE `files.view` step and the step carries the action's name (`groups.undo.by|then|token|contains|none|move|join|new|rename|ungroup`, `step()` in `gruppi.js` changes `w` of the last entry of `STORIA.pila`); rename and split go through `GRUPPI.rename/ungroup`, which also write the table rows.
  During dragging `renderFileList` waits (`GDND.busy`) and redraws once at the end; `.gdnd-over` highlight (outline and tint), announcements in `#gdnd-live` (`role=status`), Esc cancels (with a finger), auto-scroll at 40 px from the edges of `#sb-panels`.
  Without dragging: "Move to group ▸" in the row menu (groups, "New group…" with the name from `nome_gruppo`, "Ungrouped") and Ctrl+Shift+↑/↓ on a row (previous/next group, focus stays on the row).
  The load table uses the same pieces (`gruppi-tab.js`, `data-loading.md`): `GRUPPIPER.open("tb-by")` for "Group by", `GDND.startT` / `moveMenuT` for dragging and the menu, a second host in `GDND.bind`; the groups are also on `ST.files` (`GRUPPI.stg/adopt/expect/arrive`).
  **Unique names**: two groups never have the same name, ignoring case, spaces and `_` (`clash()` in `gruppi.js`, also compares the group names per experiment type): `set()` and `rename()` refuse with the note `groups.clash` (`set` returns `false`), `newName()` proposes a free one, `fit()` adds " (2)" to conflicting "Group by" labels. The same identical name joins the group.
  **Dragging**: a file enters a user group, leaves onto its own per-type group (= no group) and another type's per-type group refuses (a file never changes experiment type); test `e2e_gruppi_nomi`.

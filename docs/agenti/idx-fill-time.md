# Fill time per scan: index version 4 and the ions of `spectrum get --sum`

- **Source**: the ion injection time of a scan, `MS:1000927` in its `<scan>` (Thermo mzML, ms). `scantable::fill_of_terms` keeps a positive finite number, else none; `scantable::inert` lists the accession so an extra that carries it is read from the header text. The readers of vendor files write none (they do not expose the time).
- **Index**: version 4 (header, `idx_newer::VERSION_MAX`) adds column 23 `fill` to the scan rows: the time in ms as the shortest text of an `f32`; the 21st and 22nd columns are `null` when the scan has no type or mobility, and a scan without a time has 20 to 22 columns as before. `idxread::Scan::fill_ms` reads it; `Index::version` says which version was opened.
- **Old indexes**: version 3 is still read (`idxread::nativo` accepts 3 and 4), no scan has a time. The CLI cache key carries the format (`idx_cache::key_of`), so the CLI builds a version 4 index by itself; the site keeps the old one (`manifesto.js`: `CORRENTI.idx` 3 on purpose, `MASSIMI.idx` 4). Version 5 and above is `error.newerFormat` (`new-format.md`). The Python reference reader and writer stay at version 3 (parity of the arrays, not of this column).
- **Sum** (`specsum.rs`, `/api/specsum`, `spectrum get --sum`, `data-channels.md`): `ions` is the sum over the scans of cps x time. `fill_time.source` is `user` (`--fill-ms T` for every scan, it wins and says so), `file` (the file's times: `ms` the mean, `min_ms`, `max_ms`, `n_timed`) or `none` (`ms` null, `ions` null, `note` `note.spec.sum.noFill`, or `note.spec.sum.noFillOld` when the index is version 3: build it again). When only some scans state a time, `ions` is null with `noFill` (a part of the scans would understate them); `by_scan_type[].ions` follows the same rule per type.
- **Tests**: `specsum_tests.rs` (per-scan times, override, partial, version 3 header, plain version 4), `scanrow/tests.rs` (column 23), `tests/test_spec_sum_wasm.py` (wasm = CLI on `dati_sintetici.ms2(..., fill_ms=)`), `newer_format.rs` (5 is newer).

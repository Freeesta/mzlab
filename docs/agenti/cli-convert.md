# `mzlab-cli convert`: conversione in mzML
Parte della riga di comando (`cli.md`); il passo `convert.mzml` e le sue scelte stanno in `cli-passi.md`.

- `mzlab-cli convert INGRESSO... --out CARTELLA [--compression standard|smallest|none] [--zlib N] [--numpress] [--peaks file|profile|mzlab] [--workers N] [--report FILE.json] [--fresh] [--set conv.NOME=VALORE...]` (`convert.rs`, `convert_report.rs`; prove in `convert_tests.rs` con `convert_fixtures.rs`): chiamante sottile dell'esecutore di `convert.mzml` (`flow_base::convert_job`, che legge `zlib_level`, `numpress` e `peaks`). Piano di un passo `conv` (un ingresso per file o campione), cache in `CARTELLA/.convert`, `NOME.mzML` in `CARTELLA`.
- `--peaks` sceglie i picchi scritti (valore sbagliato: uscita 2); un campione a profilo con `file` resta a profilo e il piano registra `warn.flow.profile`.
- Ingressi: un file, una cartella dei produttori (`.D`, `.d`, `.raw`) o una cartella scorsa in ordine di nome (solo le estensioni di `mzlab_lettori::estensioni()`, mai `--out`). Un insieme con più campioni dà `NOME-ID.mzML` per campione; a nomi uguali si tiene l'estensione dell'ingresso.
- `--compression` è la forma breve delle tre scelte del dialogo «Scarica come mzML» della pagina (standard = zlib livello 2, smallest = zlib + MS-Numpress, none = array non compressi) e dà `zlib_level` e `numpress` (`convert_report::compression_sets`).
- Byte di `flow run` con un piano `convert.mzml`, indipendenti da `--workers` (predefinito `budget_auto::convert_workers`, nota `warn.convert.fewerWorkers` come l'app); un file già convertito (stessi SHA-256, parametri, programma) si salta, `--fresh` lo rifà. Avanzamento su stderr; stdout elenca gli mzML.
- `--report`: array con `{ingresso, uscita, sha256, spettri, secondi, saltato, conv/1, avvisi, centroidi}` (`centroidi` `{merged, saturated}` con `--peaks mzlab`, `cli-passi.md`) o `{ingresso, errore, causa}`. Uscita 0 bene, 1 file in errore (altri scritti), 2 uso o uscita sopra un ingresso, 3 lettura parziale (`conv/1.parziale`), 4 ingresso mancante o vuoto.

# Gruppi di esperimenti in Tabui: condizioni a confronto (`gruppi/1`)

Modulo Rust puro `crates/mzlab-feat/src/gruppi/` (`mod.rs` tipi e `build`, `presenza.rs` condizioni e presenza, `forme.rs`, `insiemi.rs`, `prev.rs`, `json.rs`): confronta la stessa degradazione in più condizioni su UN allineamento. Non legge file né riallinea mai: usa le righe che riceve. Schema `docs/schemi/gruppi-1.json`; progetto e pacchetti in `docs/studi/TABUI_GRUPPI_ESPERIMENTI.md`. Tabui è solo in inglese: nessuna chiave `lang/`.

## Ingresso e uscita
- `GroupTable {n_rows, n_files, area, height, state, apex_rt, rows: Vec<RowMeta>}` (celle `riga * n_files + file`; `state` come `table::CELL_*`, un `TARGETED` conta rilevata), `&[Campione]` nello stesso ordine delle colonne, `GroupOpts`. `RowMeta {id, tp_name, mz, polarity, rt, neutral_formula, ppm, is_parent, ms2_files, other_polarity}`: i campi HR e `other_polarity` li riempie il chiamante (Dig LR, tabella HR); `ms2_files` = file con MS2 abbinata.
- `build(..) -> GroupsOut`, `gruppi_json(..) -> String` (chiavi inglesi, ordine fisso, numeri come `Out::num`; rapporti, `cv` e `rate_rel` a 6 decimali). `run_json(bytes)` legge `{"table":{matrici come liste di righe},"campioni":campioni/2,"opts":{..}}`.
- Opzioni: `reference` (null = nessun rapporto), `min_rep_frac` 0,5 (0, 1], `min_area` 0 (spenta), `ctrl_ratio` 0,2, `shape_drop` 0,3 (0, 1], `norm` solo `"raw"`, `factors` (condizione → chiavi/valori stringa, riportati in `conditions[].factors`, mai usati). Errori `error.gruppi.noConditions`, `badOpts` (param = nome dell'opzione; `norm=istd`; `factors` non stringa o con condizione inesistente), `sizeMismatch` (param `what`).

## Regole
- Condizioni = valori distinti non vuoti di `serie` dei campioni con `role() == "sample"`, nell'ordine della più piccola `ordine_iniezione` (non dell'indice di colonna: così l'uscita non dipende dall'ordine dei file). Ogni elenco di file è ordinato per (ordine, nome): somme e byte identici per qualunque permutazione delle colonne (indici a parte).
- Controlli (t0, bianco, std, buio) per tipo: i file della condizione se ce ne sono, altrimenti quelli con `serie == ""`. Repliche = file con lo stesso (condizione, `tempo_min`); un tempo ignoto forma un gruppo a sé (conta per la presenza, non per `kin`).
- Area di un gruppo = media delle repliche rilevate (sd campionaria, `cv = sd/area`); se nessuna è rilevata, media delle riempite (si vede quanto «assente» è assente); altrimenti 0. `area`, `n_det`, `n_rep` sono quelli dell'ultimo tempo.
- `present` = rilevata in almeno `ceil(min_rep_frac · n)` repliche di un tempo trattato, con area media ≥ `min_area`; le celle riempite non contano. `only_in` e `in_all` solo con ≥ 2 condizioni. `sets`: combinazioni esatte (mai vuota), per numero di righe decrescente poi per nomi.
- `ratio_ref` = area(cond)/area(rif) al tempo più alto che hanno in comune; 1 per il riferimento, 0 se la condizione non è presente, null se il riferimento è assente, non c'è riferimento o non c'è tempo comune.
- `shape` (solo dove presente): `single` (un tempo), null (due), poi `flat` (max/min < 1,5), `rising` (massimo all'ultimo tempo, o calo dopo il massimo < `shape_drop`), `bell` (calo ≥ `shape_drop`), `decay` (massimo al primo). `t_half_rise` (interpolato) solo per `rising` e `bell`; `rate_rel = t_half_rise(rif)/t_half_rise(cond)`.
- `prev` (null se non presente o se la riga è `is_parent`): `absent_t0`/`absent_blank` pass se l'area massima rilevata nel controllo ≤ `ctrl_ratio` · area massima trattata; `in_parent_std` yes se la supera (solo suggerimento, mai esclusione); `above_min` na se `min_area` = 0; `ms2` na se nessuna riga ha MS2. Verdetto: «Prev. unlikely» se t0 o bianco hanno lo ione; «Prev. possible» se lo ha lo standard del parent o manca t0/bianco o la MS2 non è abbinata; altrimenti «Prev. likely». Nessun livello di Schymanski, nessuna riga tolta.
- `parent` per condizione: riga con `is_parent`, `legacy::lr::kin::decay` sui tempi rilevati (k, t½ con ≥ 3 punti) e `remaining` = area all'ultimo tempo / area media del t0 della condizione.
- Avvisi (ordinati per codice, poi condizione): `refMissing`, `condNoControls` (né t0 né bianco), `condOnePoint`, `condNoReplicates` (nessun tempo con ≥ 2 repliche), `mixedTimes` (tempi diversi da quelli del riferimento, o della prima condizione).

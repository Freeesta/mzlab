## Da fare

4. Banco Rust `crates/mzlab-lettori/tests/comune/verita.rs` (lettura della verità, confronto F0-F5 con le tolleranze di F.2, rapporto per file `L`/`P`/`NV` con il livello che manca) e un test per famiglia `tests/verita_<famiglia>.rs` che scorre le verità del corpus (`MZLAB_DATI`) e salta senza. Prova il banco con verità costruite da mzML sintetici (CI pubblica).
5. Fuzz (F7): bersagli `fuzz/fuzz_targets/lettori_<famiglia>.rs` per ogni modulo (`riconosci` + `apri` + prime scansioni su byte arbitrari dentro un `Fs` in memoria) e la loro riga nella lista dei bersagli di `.github/workflows/fuzz.yml` (unica modifica ai workflow permessa).
6. Repository privato: proponi `mzlab-dati/.github/workflows/rosina.yml` (notte: checkout di `Freeesta/mzlab` `main`, `cargo test -p mzlab-lettori --features tutte --test 'verita_*'` sulle verità ≤ 90 MB, riassunto formato × livello come artefatto). PR nel privato (accesso con `add_repo`, push), merge solo con il sì del Coordinatore.
7. Documenti: `docs/agenti/test.md` (una riga sul banco Rosina), `docs/studi/ROSINA.md` F se un dettaglio cambia.

## Atteso

Also `JsReader: ReadAt` is copied in `mzlab-feat-wasm/src/lib.rs:92`, `mzlab-feat-table-wasm/src/lib.rs:42`, `mzlab-finder-lr-wasm/src/lib.rs:18` (the last already depends on `mzlab-feat-wasm`).

Prompt pronto per una chat DEV: copia tutto ciò che segue la riga «---».

Pacchetto DEV-01 dello studio `docs/studi/FORMATI_NATIVI_MS.md`: mzML con numpress.
File d'area da leggere oltre a quelli comuni: docs/agenti/lettori-modulo.md, docs/agenti/mzidx.md.

## Obiettivo
Un mzML con array MS-Numpress (msconvert `--numpressLinear/--numpressPic/--numpressSlof/--numpressAll`) oggi dà `err.file.numpress` (`crates/mzlab-core/src/mzml.rs:412-413`). Deve aprirsi: il modulo lettori lo riscrive come mzML zlib in OPFS (regola R, caso «variante»).

## Da fare
1. `crates/mzlab-core/src/numpress.rs` solo con `#[cfg(feature = "estesi")]`: decodifica di linear prediction (MS:1002312), positive integer (MS:1002313), short logged float (MS:1002314) e delle loro forme seguite da zlib (MS:1002746, MS:1002747, MS:1002748), dalla specifica pubblica MS-Numpress (riferimento C++ con licenza libera: verificala e citala). Ogni lunghezza letta passa da un limite (la lunghezza attesa dello spettro, come `decode_array`).
2. `mzml.rs::decode_array` e il riconoscimento degli accession (`mzml.rs:405-415`): con `estesi` decodifica, senza resta l'errore di oggi (il motore non cambia).
3. `crates/mzlab-lettori/src/mzml_numpress.rs`: un `Lettore` sopra un mzML numpress: `riconosci` = testa XML mzML + un accession numpress nei primi 64 KB (`Fiducia::Si`); l'indice delle scansioni si costruisce con una sola passata a offset (riusa `crates/mzlab-core/src/scantable.rs`, che trova l'inizio e la fine di ogni `<spectrum>`, senza tenere il file in memoria); `scansione(c,k)` legge solo i byte di `k` e li passa a `mzml::parse`. `cromatogrammi` come `mzmlhead.rs`. `testata_mzml`: la testata originale (strumento, sorgenti, SHA-1, software) più «mzLab» come software di conversione. `metodo(c)`: se l'mzML porta `mzLab metodo/1` lo ripete, altrimenti assente (il documento per gli mzML di altri è DEV-14).
4. Pagina: niente di nuovo se DEV-0 ha la regola R per `err.file.numpress`; verifica con un e2e (estendi `tests_e2e/e2e_lettori_modulo.py`): un mzML numpress costruito dal test apre, TIC e uno spettro uguali al gemello zlib entro la precisione di numpress.
5. Test: vettori di codifica/decodifica scritti nel test Rust (codificatore nel test), confronto con la tolleranza nota di ogni codec (linear: errore assoluto ≤ 1/(2·fattore); slof e pic: relativo dichiarato); caso ostile (lunghezze false, zlib che si gonfia oltre il dichiarato); parità sui dati veri: lo stesso file con e senza numpress (salta senza `MZLAB_DATI`).

## Atteso
Un mzML numpress apre nella vista Dati come il suo gemello; motore invariato; riga «mzML» di `FORMATI_NATIVI_MS.md` aggiornata.

## File reali
1 mzML scritto con `msconvert --numpressAll` (meglio 2: un full scan LR del 3200 e un HR) di file che sono già nel repository privato, accanto al loro mzML senza numpress.

2. **Goal**: dragging a file row onto a user-group header adds it to that group; onto «Ungrouped» (or the gap after the last group) removes its label; the ticked companions move with it when the dragged row is ticked; one undoable step per drop (`GRUPPI.set`), `E.ugBy.by = "custom"`.
   - Feedback: the target header gets a highlight class from CSS variables (no layout change: outline/background only), a live region (`role=status`, the list's existing one if any) says «Move to MQ · 3 files» while hovering and «Moved to MQ» after the drop; Esc during a drag cancels.
   - Repaints: while a drag is active, `renderFileList` calls coming from file arrivals (D3) are deferred and applied once on drop/cancel (one flag in `gruppi-dnd.js`, read by `renderFileList`).
   - Touch: the existing 350 ms long-press starts the drag; auto-scroll near the top/bottom 40 px of `#flst`; drop targets are headers only on touch.
   - **Alternatives (required, same PR)**: «Move to group ▸» in the row context menu (right-click, Menu key, Shift+F10) lists the groups, «New group…» (asks a name, default from `nome_gruppo` of the selection or «Group N») and «Ungrouped», acting on the selection; keyboard pick-up: with a row focused, Ctrl+Shift+↑/↓ (or Space on the row grip if there is one) moves the file to the previous/next group, announced in the live region.
   - Moving never changes role, time or concentration; the experiment-type sections of LR cannot be dropped into (a Full Scan file stays in Full Scan).

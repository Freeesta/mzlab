=== mzlab-cli 
exit 0
--- stdout
mzlab-cli: LC-MS analysis from the command line, the engine of the mzLab app; the files never leave this computer.

Start here:
  mzlab-cli flow steps --json                  the catalog of the Flow steps: ids, parameters, ports (what an analysis can be made of)
  mzlab-cli flow check PLAN.json --json   is a plan valid, with every problem named
  mzlab-cli flow run PLAN.json --in FILE... --out FOLDER   run a whole plan
  mzlab-cli COMMAND --help                the help of one command: on stdout, exit 0

For scripts and agents: --json is accepted by every command (the data as JSON on stdout; a failure is one error/1 document on stdout, the
text on stderr); progress goes to stderr. Exit codes: 0 ok; 1 data or domain error (partial outputs written); 2 usage; 3 plan, schema or
integrity; 4 input missing or unreadable; 5 selector not found (sample, channel, node, step instance); 6 output write or external source failure; 7 internal error (a bug); 8 input still being written (retry when it ends).

usage: mzlab-cli features FILE... [--sample LIST] [--centroid auto|on|off] [--mz-offset DA|auto:MZ[@RT]] [--report PATH] [--dry-run] [--out PATH] [--notes PATH] [--preset auto|pos|neg | --params FILE.json]
       mzlab-cli table compare TABLE --ref SEL --blank SEL [--samples FILE.json] [--quantity area|height] [--factor F] [--pseudocount auto|N] [--format json|csv] [--json] [--dry-run] [--out PATH]   each feature vs the reference and the blank: candidate products
       mzlab-cli quant targets --targets FILE INPUT... [--da D] [--min-sn N] [--offset 0|DA|auto|auto:MZ[@RT]] [--blank-pattern GLOBS] [--set NAME=VALUE...] [--log PATH] [--format csv|json] [--json] [--dry-run] [--out PATH] [--workers N]   targets integrated in every file
       mzlab-cli flow run PLAN.json [--in FILE|FOLDER...] --out FOLDER [--set INSTANCE.NAME=VALUE...]   a whole Flow plan
       mzlab-cli flow check PLAN.json [--set INSTANCE.NAME=VALUE...] [--json]   is the plan valid, without the input files
       mzlab-cli flow steps [--json] [--compact] [--id ID[@V] [--template]]   the Flow steps, native or page only; --template a one-step plan
       mzlab-cli flow report RUNDIR [--out FILE]   a run's report
       mzlab-cli flow record RUNDIR --roles ROLES.json [--out FILE]   the mzrun/2 record of a run
       mzlab-cli flow verify RECORD   whether an mzrun/1 record's fingerprints match its files
       mzlab-cli flow command PLAN.json [--json]   the rerun script
       mzlab-cli file list DIR [--json] [--out PATH]   what «Open folder» lists, .D / .raw folders included
       mzlab-cli file info FILE... [--sample LIST] [--out PATH]   what a file holds: container, samples, items, channels, proposed kind
       mzlab-cli file index FILE... [--sample ID] [--out PATH]   pre-build the index cache as JSON
       mzlab-cli file inventory FILE.wiff... [--full]   what a .wiff + .wiff.scan holds per sample, SHA-256 and status
       mzlab-cli file verify OUT.wiff --against SRC.wiff...   whether an output equals its sources
       mzlab-cli file items FILE [--no-points] [--out PATH]   what the page learns about a file: counts, ranges, ms2_exps with CE
       mzlab-cli file channels FILE [--sample LIST] [--out PATH]   the channels of a file as JSON
       mzlab-cli file pair FILE... [--json]   the other half of a SCIEX pair found by name
       mzlab-cli file validate FILE.mzML... [--json]   is the mzML valid: structure, vocabulary, index and SHA-1
       mzlab-cli file convert INPUT... --out FOLDER [...]   vendor files to indexed mzML
       mzlab-cli sample vars NAME...   how file names split into variables
       mzlab-cli sample group NAME...   the file names' group name
       mzlab-cli sample table NAME...   the sample table for the file names
       mzlab-cli sample list FILE...   what a file holds per sample
       mzlab-cli sample select FILE --sample LIST   which samples LIST picks
       mzlab-cli sample design propose [FILE...] [--samples S.json] [--out PATH]   propose a design from names
       mzlab-cli sample design validate DESIGN.json [--samples S.json]   check a design, name bad keys
       mzlab-cli sample design canonical DESIGN.json [--out PATH]   canonical bytes and SHA-256
       mzlab-cli trace chrom FILE --id ID [--sample ID] [--rt A,B] [--n N] [--format json|csv] [--out PATH]   a channel trace as JSON or rt_min,intensity CSV
       mzlab-cli trace xic FILE (--mz M[,M..] | --sweep LO:HI:STEP) [--ppm P | --da D | --tol T] [--smooth 3|5] [--rt A,B] [--ms-level N] [--polarity +|-] [--sample ID] [--format json|csv] [--out PATH] [--dry-run]   XICs of m/z: trace/1, trace-set/1, CSV; --mz needs a tolerance; --dry-run xicplan/1
       mzlab-cli trace background FILE [--set NAME=VALUE...]   the background trace of a file as JSON
       mzlab-cli dad subtract FILE ...   the DAD matrix A minus B
       mzlab-cli dad spectrum FILE ...   the UV spectrum at a time
       mzlab-cli dad trace FILE ...   the UV trace at a wavelength
       mzlab-cli dad ms-at FILE ...   the MS linked to a DAD time
       mzlab-cli dad delay FILE ...   the delay between the DAD and the MS
       mzlab-cli dad peaks FILE ...   UV peaks, lambda-max, MS ions
       mzlab-cli spectrum get FILE (--rt MIN | --rt A,B | --scan NO) [--ms-level N] [--id CHANNEL] [--sample ID] [--minus FILE] [--minus-sample ID] [--minus-rt A,B] [--format json|csv] [--out PATH]   one spectrum as JSON or mz,intensity CSV, optionally minus a blank
       mzlab-cli spectrum list FILE [--ms-level N] [--id CHANNEL] [--sample ID] [--format json|csv] [--out PATH]   the scans of a file (number, level, rt, TIC, precursor, base peak)
       mzlab-cli spectrum dda-window FILE --from MIN --to MIN   the MS2 of a window by precursor
       mzlab-cli peak auto TRACE.csv|- [--from MIN --to MIN] [--baseline zero|edges|line] [--set NAME=VALUE...]   every high-resolution peak
       mzlab-cli peak auto-lr TRACE.csv|- [--from MIN --to MIN] [--split drop|valley] [--set NAME=VALUE...]   every peak of a low-resolution SIM/MRM trace
       mzlab-cli peak noise TRACE.csv|- [--rt A,B] [--set NAME=VALUE...]   one-ion noise floor, peak S/N
       mzlab-cli peak edges TRACE.csv|- --at MIN [--noise mad|rms|manual] [--set NAME=VALUE...]   limits of a low-resolution peak
       mzlab-cli peak area TRACE.csv|- --from MIN --to MIN [--baseline zero|line] [--set NAME=VALUE...]   one peak from zero or a line
       mzlab-cli peak window TRACE.csv|- --end MIN --other MIN [--at MIN] [--step N]   where a dragged window end goes (--at or --step)
       mzlab-cli peak split FILE... --tr J --a MIN --b MIN [--baseline zero|edges|line] [--split auto|MIN,...]   one peak split at its valleys
       mzlab-cli peak table FILE... --windows PATH [--traces PATH] [--columns sn,fig,quality] [--max-shift MIN] [--json]   hand integrations of transition / SIM traces, as CSV
       mzlab-cli msn graph FILE.mzML [--formula ION] [--summary] [...]   the fragmentation graph of an MSn infusion
       mzlab-cli msn complete GRAPH.json ...   the graph completed with the missing nodes
       mzlab-cli msn compare GRAPH.json GRAPH.json ...   two graphs side by side
       mzlab-cli msn figure GRAPH.json ...   the figure of a graph
       mzlab-cli msn lib add LIB.json FILE.mzML --id ID --formula ION [--dry-run]   add an infusion to the MSn library
       mzlab-cli msn lib build MANIFEST.tsv [--dry-run]   build the MSn library
       mzlab-cli msn lib export LIB.json   export the library spectra
       mzlab-cli msn lib search ...   search the library of MSn trees
       mzlab-cli msn rules RECORD... [--rules] [--decoy SEED]   the fragmentation rules judged on library spectra
       mzlab-cli msn rules sum DOC...   the msn-rules/1 documents summed
       mzlab-cli ion mz TEXT [--adduct A]   the m/z of an ion with a signed shift
       mzlab-cli ion pattern FORMULA ADDUCT [--out PATH]   the unit-resolution isotope pattern of an ion
       mzlab-cli ion match X --tables FILE.json [--set hr=1 ppm=N]   what a number is compatible with: losses, adducts, contaminants
       mzlab-cli ion elements [--json]   the periodic table (elements/1)
       mzlab-cli mol label REQUEST.json|- [--out PATH]   formula, charge and masses of structures and arrows
       mzlab-cli mol anal REQUEST.json|-   average mass, mass % and isotope pattern of one structure
       mzlab-cli mol check REQUEST.json|- [--out PATH]   what is wrong in a drawing (valence, charge, isotope, wedges)
       mzlab-cli mol cip REQUEST.json|-   the R/S and E/Z of a drawing
       mzlab-cli mol measure REQUEST.json|-   logP, TPSA, H-bond counts, rotors, formula analysis of a drawing
       mzlab-cli mol hilite REQUEST.json|-   the atoms an evidence colours
       mzlab-cli mol sel REQUEST.json|-   masses, heavy atoms and rings of a selection
       mzlab-cli mol link REQUEST.json|-   PubChem, ChEBI and BioTransformer URLs
       mzlab-cli mol draw SPEC [--format molfile|scene|ket|cdxml|svg|png] [--set NAME=VALUE...] [--out PATH]   molfile, KET, CDXML, picture or --json scene; --set edit=JSON|@PATH patches it
       mzlab-cli mol export MOLFILE|-   the drawing as .mol or .sdf
       mzlab-cli mol open FILE|- [--check]   the text the editor reads for a file
       mzlab-cli mol cut MOLFILE|- --set bonds=A-B[,...] [--set NAME=VALUE...]   the pieces of a homolytic, heterolytic or +H cut
       mzlab-cli mol mech REQUEST.json|-   whether the curved arrows of a mechanism are well formed
       mzlab-cli mol search --sub QUERY TARGET...   where a substructure occurs in structures
       mzlab-cli db normative build --cache DIR --out DIR   the EU and US regulatory lists from official sources (native only)
       mzlab-cli db normative pack ...   pack the regulatory lists (native only)
       mzlab-cli db normative listings ...   the regulatory lists built (native only)
       mzlab-cli db normative import-official ...   import the user's official lists (native only)
       mzlab-cli db insilico pack CSV OUT   the spectra.insilico candidate package (native only)
       mzlab-cli db ref-list FILE.csv [--name N] [--match X]   a CSV of reference ions as JSON (reflist/1)
       mzlab-cli llm tools [--out FILE] [--demo] [--compact]   the assistant tools (tools/1)
       mzlab-cli llm inspect FILE|DIR... [--budget N] [--hide-names]   inspect mzML files
       mzlab-cli llm params [FILE|DIR...] [--inspection FILE|-] [--answers FILE] [--budget N] [--hide-names]   propose parameters by rules
       mzlab-cli llm context RUNDIR [--budget N] [--hide-names]   a run folder's context
       mzlab-cli llm replay REG.jsonl --conv CONV.json [--turn N] [--strict]   replay a recording
       mzlab-cli llm eval CASES_DIR --replay DIR   score the cases
       mzlab-cli completions bash   the bash completion script, on stdout
       mzlab-cli completions zsh   the zsh completion script, on stdout
       mzlab-cli completions fish   the fish completion script, on stdout
       mzlab-cli commands [--json] [PATH...]   every command's arguments, flags, schema, exit codes (commands/1)
       mzlab-cli schema [--list | NAME]   the JSON Schema NAME (error/1, mzflow/2, ...) or the list (schemas/1)

If you use mzLab, please cite it: mzLab {VERSION}, https://github.com/Freeesta/mzlab, DOI: to be added

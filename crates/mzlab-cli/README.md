# mzlab-cli

Command line of mzLab (`mzlab-cli`): runs the feature engine, the `mzflow/2` plans and other steps from the shell.
A thin native wrapper over `mzlab-core` and `mzlab-feat`, so the numbers are those of the page; never in the WASM graph.
Used by the Flow, by CI and by external agents.
Area file: `docs/agenti/cli.md (agents: per-agenti.md)`.

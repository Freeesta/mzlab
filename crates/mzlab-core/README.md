# mzlab-core

Core engine of mzLab in pure Rust: mzML and vendor-file reading, `.mzidx` index, TIC/XIC, spectra, peaks, formulas, MRM.
Compiled to WASM by `mzlab-wasm` for the site and linked natively by the desktop app and the CLI; no native dependencies in the WASM graph.
Area file: `docs/agenti/rust.md (routes: rust-rotte.md)`.

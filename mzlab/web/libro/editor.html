Connect to GitHub

The Libro is private, so this page needs a key (a "token") that works only on the mzlab-dati repository. You create it once:

  1. On GitHub: your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: "Libro editor". Expiration: 90 days. Repository access: Only select repositories → mzlab-dati.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  4. Click Generate token and copy the text (it starts with github_pat_). Paste it below.

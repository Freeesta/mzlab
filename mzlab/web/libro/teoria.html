Connect to GitHub

Paste the github_pat_… key in the Token field; the passphrase is a word you invent.

Sending a change opens a pull request on the public mzlab repository, so this page needs a key (a "token") that works only there. You create it once:

  1. On GitHub: your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: "Teoria editor". Expiration: 90 days. Repository access: Only select repositories → mzlab.
  3. Permissions → Repository permissions: Contents: Read and write and Pull requests: Read and write. Nothing else.
  4. Click Generate token and copy the text (it starts with github_pat_). Paste it below.

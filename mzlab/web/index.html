XIC (Extracted Ion Chromatogram): il cromatogramma dei soli segnali con m/z dentro un intervallo largo 1 Da attorno alla massa nominale dello ione. Si integra da qui. In ogni riga scrivi un m/z oppure una formula neutra (con l'addotto).

Non hai file mzML?

  1. I file Waters, Shimadzu e Bruker non si leggono direttamente: convertili in mzML con MSConvert. Scarica ProteoWizard (contiene MSConvert), gratis, per Windows: proteowizard.sourceforge.io.
  2. Apri MSConvert, trascina i tuoi file (.raw, .wiff, .d…) nell'elenco e premi Add (un .wiff deve stare accanto al suo .wiff.scan).
  3. Formato di uscita: mzML. Le impostazioni predefinite vanno bene così: non cambiare altro.
  4. Premi Start: i file .mzML compaiono nella cartella di output.
  5. Carica qui i .mzML.

I file .raw non serve convertirli: trascinali nel riquadro qui sopra e l'app li converte.

2. Metodo di acquisizione

File in profilo ad alta risoluzione: molto pesante. Convertilo con il peak picking del vendor, per esempio msconvert file.raw --mzML --zlib --filter "peakPicking vendor msLevel=1-" (ricetta completa nella guida, «File ad alta risoluzione e file grandi»).
Alcuni file sono in profilo e altri centroidi: le intensità dei due gruppi non sono confrontabili.
